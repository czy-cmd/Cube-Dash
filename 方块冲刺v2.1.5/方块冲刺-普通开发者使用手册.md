# 方块冲刺 · 普通开发者使用手册

> 版本对应：v2.1.5（设计 v2.6）
> 面向对象：想二次开发、加玩法、改配置的人。
> 玩家视角见《方块冲刺-玩家使用手册.md》。
> **保密级别：内部**。本册不含后台管理密码、等级码明文、编码密钥等最高机密——那些只在《方块冲刺-总开发者使用手册》里。

---

## 1. 工程概况

- **形态**：单个 `方块冲刺.html`，零依赖、零外部请求（音乐功能开启时除外）。
- **技术栈**：HTML5 + Canvas 2D（渲染）+ Web Audio（实时合成音效，`audioCtx` 为 null 时全部静默）+ `localStorage`（存档）。
- **脚本结构**：全部逻辑包在一个 IIFE 里：
  ```js
  (function(){'use strict'; ... })();
  ```
  顶层变量（`CONFIG` / `state` / `G` / `save` / `expFlags` / `curDiff` 等）都是 IIFE 内的 `var`，**不挂到 window**。要测试或导出，必须在 `})();` 之前注入导出语句（见 §8）。
- **状态机**：`state` ∈ `menu / playing / paused / adPaused / over`；各 UI 是 `.layer` 面板，`layer(id)` 负责显隐 + 切 HUD。
- **坐标系**：`dirSign` 控制障碍下落方向（普通 +1 从上往下，倒车 -1 从下往上）；`LANES` 为车道数（默认 3，多车道实验可到 10）。

## 2. 核心常量 `CONFIG`（约 684 行）

| 字段 | 用途 |
|------|------|
| `CONFIG.saveKey` | localStorage 键名 `fkcc.save.v1`；改它等于换一份新存档 |
| `CONFIG.diffs` | 五档难度 `easy/normal/hard/extreme/disabled`，每项 `{name, mul, extreme?, disabled?}` |
| `CONFIG.stages` | 速度 / 生成参数分段时间轴，每项 `[阈值秒, mul, a, b, 波序]` |
| `CONFIG.thresholds` | 普通模式出口阈值 `[100,500,1000]`，之后 ×2 |
| `CONFIG.obsTypes` | 5 种障碍定义（见 §4） |
| `CONFIG.palettes` | 三套配色，开发者面板可切 |
| `CONFIG.doubts` | 英文哲学疑问字幕池（打字机式，**不是**恐怖独白） |
| `HORROR_DOUBT` / `HORROR_LATE` | 恐怖模式中文独白池（模块级数组，非 CONFIG）：前期 / 第 4 波起 |
| `CONFIG.functions` | 功能名列表（百分比解锁用） |
| `CONFIG.appVersion` / `designVersion` / `author` | 版本号 / 设计版本 / 作者；发布前记得改并与 `LOG` 对齐 |
| `CONFIG.slowDur/slowCd/slowScale` | 慢放技能：持续 4 秒 / 冷却 10 秒 / 0.5× |

## 3. 命令系统（`applyCommand`，约 1840 行）

`applyCommand(low, p, raw)` 收到：

- `low`：整条命令小写。
- `p`：按空白 `split(/\s+/)` 的词数组。
- `raw`：原始字符串（带大小写，给需要原样密码的命令用）。

### 3.1 解析约定

- 每个命令是一个 `if(p[0]==='xxx'){...}` 分支，最后落到 `return{text:'unknown command'};`。
- **带连字符的命令**要先归一化：分支内把 `-` 换成空格再 split，或用 `p[0].indexOf('about-')===0` 前缀判断再 `slice(6)`。
  - `tp`：`var tp=(low.replace(/-/g,' ')).split(/\s+/);`
  - `about`：`var sub=(p[0]==='about')?p[1]:p[0].slice(6);`
- 返回值 `{text, fx?}`：`text` 显示在输出区；`fx:'flash'` 触发闪屏。

### 3.2 已实现命令（普通向）

| 命令 | 实现要点 |
|------|----------|
| `get from enter/in/into` | 设 `exitMode` |
| `get from percent N` | 设 `percent`（百分比解锁） |
| `url-…` / `url-none` | `addUrl()` 定时 `window.open` |
| `kb-true` | `horrorStory=true` → `applyHorrorVisual()`（会话级，不写存档） |
| `kb-false` | `endHorror()` 统一收尾 |
| `tp N [next\|M.ago]` | 立即 `G.wave=N-1`；预约 `tpPending={target,after}` |
| `about-things` | `save.aboutThings++` 永久写存档 |
| `about-choose` | `chooseNoSave=!chooseNoSave` 会话级 |
| `about-command` | `cmdMode=true; buildCmdBook(); layer('cmdMode')` |
| `about-game` | `startGame()` |
| `about-use` | 拼调试 log（各难度 mul、当前难度、种子、模式码、恐怖/命令状态） |

> 另有一批维护 / 后台命令**不在本册**，见总开发者手册。别把它们写进玩家手册或命令书。

### 3.3 如何新增一条命令

1. 在 `applyCommand` 加分支（注意连字符 / 大小写）。
2. 想让它在「书」里露脸，往 `COMMANDS` 数组（约 1330 行）加一行 `[命令, 说明]`。
3. 若影响难度 / 实验 / 存档，同步 §4、§5、§7 与手册。
4. 跑 §8 冒烟测试，并在 `LOG` 数组补更新日志。

## 4. 障碍系统

`spawnObstacle()`（约 845 行）负责生成，`update()` 负责行为，`render()` 负责绘制。

| 类型 key | 名称 | 行为要点 |
|---------|------|---------|
| `single` / `double` | 单块 / 双块墙 | 基础障碍，按波次权重出现 |
| `wide` | 巨墙 | 横贯跑道只留一道 `gap`，`LANES>=3` 时才生成 |
| `rush` | 急坠 | `mul=1.6` 下落加速；1 车道模式点 3 下消除 |
| `phase` | 相位 / 隐身 | `phaseT` 周期切 `solid`，虚化态不判死；「现」技能可逼出逃跑 |
| `tracker` | 追踪 | `trackT>.55` 且接近玩家时朝玩家平移一格，只移一次 |

**按波次解锁**：`CONFIG.obsTypes[type].minWave` 控制何时进入生成池。

**防堵死**：`wouldBlockAll()` 在生成前检查同屏障碍的车道并集，避免箭头 + 双块墙把三条道全堵死。加新障碍时务必接上这个检查。

**1 车道模式**：`lane1Mode()` 下红/蓝/绿障碍 `hp=3/5/10`，点消给对应分数，`lane1Clear()` 在 150 分触发通关。

## 5. 难度系统

### 5.1 速度乘子
`difficulty()` 在每段时间轴 `mul` 上再乘 `CONFIG.diffs[curDiff].mul`：
```js
var d=CONFIG.diffs[curDiff]||CONFIG.diffs.normal;
return {mul:s[1]*d.mul, a:s[2], b:s[3]};
```
`update()` 里波次 3 特判：`*(G.wave===3?(curDiff==='disabled'?0.5:1.3):1)`。

### 5.2 入口流程
- `requestStart(fn)`：设 `pendingStartFn`；恐怖模式先把 `curDiff` 重置为 `'normal'` 再直接执行；否则弹 `diffLayer`。
- 极限 / 残疾：`pickDiff` 先弹 `diffConfirm`，`diffConfirmYes` 要连点两次才放行。
- `doStartWithDiff()`：非极限时 `exitMode=false`，执行 `pendingStartFn`。

### 5.3 极限模式
- `startGame()`：`curDiff==='extreme'` → `exitMode=true`。
- `exitThreshold(i)`：极限返回 `300*(i+1)`。
- `gameOver()` 极端分支：3 倍算 highscore → `localStorage.removeItem(saveKey)` 删档 → 重置内存 save。
- `btnQuit()`：极限下若 3 倍新高，主动写回存档（「见好就收」的实现点）。

### 5.4 残疾模式
`move(dir)` 在 `curDiff==='disabled'` 时随机延迟 `1000+rand(0..2000)ms` 后执行变道。

### 5.5 如何加一档难度
1. `CONFIG.diffs` 加 `{name, mul, 你的flag?}`。
2. 有出口 / 删档 / 延迟特例就在 `startGame/exitThreshold/gameOver/move` 按 `curDiff` 分支。
3. `diffLayer` 加按钮 + 绑定 `pickDiff('key')`。

## 6. 恐怖模式状态机

完整叙事见《方块冲刺-恐怖模式设计稿.md》。

`var horrorStory=false` 是**模块级会话状态**，不写存档，刷新即失。

| 函数 | 职责 |
|------|------|
| `applyHorrorVisual()` | 按 `horrorStory \|\| expFlags.horror` 挂/卸 `body.blood`、`#horror.on` |
| `endHorror()` | 唯一完整收尾：清 `horrorStory`、`#horrorFinale.on`、`#horrorText.on`、`--hgloom` |
| `closeHorrorFinale()` | 结局页点击：隐藏层 + `state='menu'` + `resetExp()` + 回菜单，**不清 `horrorStory`** |

**只在两处结束**：`kb-false` → `endHorror()`；主菜单「退出」`btnExit.onclick` → `endHorror()`。`resetExp/refreshMenu/closeHorrorFinale/死亡` 都不能清 `horrorStory`。

> ⚠️ **坑：别改 `#horror` 的 z-index**（=6）。HUD=10、`#horrorText`=8、界面层=20。提到 20 以上会盖住 HUD 和独白。
>
> ⚠️ **坑：结局页关闭必须 `state='menu'`**，否则 `loop()` 每帧重绘冻结帧 + `clearCanvas()` 永不执行，「死亡定格背景」开关失效。

## 7. 挑战码 / 种子 / 存档

### 7.1 挑战码加解密
- `CODE_KEY`（模块内常量）+ `codeSeal()` / `codeOpen()`：一套流加密同时产出密文与校验位，外层 6 位防篡改 + 内层 4 位防伪造，改任一字符都拒绝。
- 新码 `CZYFK2-…` 明文含：难度 + 每项实验 + 车道数 + 模式 + 种子 + 分数。
- `buildCond()` / `applyCond()` / `condText()`：条件编解码，`DIFF_ORDER` / `EXP_ORDER` 定顺序。
- `parseChallenge()`：新码分支解析；导入路径跳过 `requestStart` 直接 `startGame()`，仅本局生效。
- 老码 `CZYFK-XX-种子-分数` 走 legacy 分支，结算页标注无法确定模式真伪。

> 密钥值、等级码明文、专属编码算法属最高机密，见总开发者手册。本册只需知道接口怎么用，不要改 `CODE_KEY`——改了会让所有已发出的码全部失效。

### 7.2 种子
- `parseSeedInput(t)`：先识别挑战码分支；纯数字直接作数值种子（`dispSeed()` 原样显示）；普通种子只放行字母 / 数字 / emoji，其余字符拒绝并提示。
- 所有显示处统一走 `dispSeed()`：HUD、种子页、复制、结算、use log。挑战码生成仍用数值 `seed`，不用显示标签。

### 7.3 存档结构
`DEFAULT_SETTINGS` + `save` 初始 + **两处硬编码 `save={...}` 重置**（`gameOver` 极限分支、`setDelete`）必须字段一致。新增字段四处都要补，否则老存档缺 key 或删档后字段残留。

`loadSave()` 用 `DEFAULT_SETTINGS` 遍历补齐，老存档缺 key 不会炸。

> ⚠️ 两处重置还要调 `resetSkinVisual(); stopBgm();`，否则皮肤 / 音乐在删档后残留。

## 9. 皮肤 / 音乐 / 实验玩法扩展

- **皮肤**：`parseSkinCode()` / `parseSkinColor()` / `stripSkinComment()` / `applySkin()`，详见《皮肤使用方法-开发者.md》。注意 `#` 既是注释符又是色值前缀，`stripSkinComment()` 只在行首或空白后截断。
- **音乐**：`CONFIG.musicLib` / `startBgm()` / `stopBgm()` / `playBgmUrl()`。含 BV 号的链接转 `player.bilibili.com` iframe，纯音频直链才用 `<audio>`。`save.settings.bgmAudioOnly` + `applyBgmMode()` 控制仅声音（CSS 类把 iframe 收成 1×1）。
- **实验玩法**：`expFlags` 每个勾选项是一个 key；`expAny()` 任一为真即实验局。`multilane` 把车道数写 `expFlags.lanesN`。`noRecord()` = `expAny()||challengeExp||commandActive`。模式码 `modeCode()` 按组合返回 `PT/EX/CM/MX/DV`。详见《方块冲刺-扩展的实验性玩法.md》。

## 10. 维护红线（务必遵守）

1. **玩家手册零敏感内容**：玩家向 md/txt 不得出现后台命令、密码、账户管理、等级码任何内容。测试有断言守着，改文档后务必重跑。
2. **项目内零指定字眼**：html 里不出现「官方」二字，等级码机制统一用「等级码 / 专属编码」描述。
3. **命令别名全局查重**：`build_table` 后注册会覆盖同名别名，加别名前全局搜一遍。
4. **模块内别用外部别名**：`commands.py` 那套坑在 html 里对应的是——IIFE 内函数名直接用，别假设有全局别名。
5. 改存档字段、难度、命令后，三本手册与测试同步更新。
