> 版本：v2.1.5（设计 v2.6）
> 本版接续 v1.6.0：修复挑战码条件丢失，新增音乐显示模式、障碍教程与技能、一车道通关玩法、商店与金币、等级码、账户与后台管理。

## 1. 挑战码重做（核心修复）

### 1.1 问题

老格式 `CZYFK-XX-种子-分数` 中间只有 2 位大类（PT/EX/CM/MX/DV），**不含难度、不含具体开了哪几项实验性**。结果：你「全实验性 + 困难」导出，好友导入后变成「PT + 他自己的默认难度」，条件不一致根本没法比。

> 「不改动他的设置」的正确含义：好友**本局**严格按挑战码里的条件跑，但他的存档设置保持默认/原样，不写入、不覆盖。重开还是他自己的模式。

### 1.2 新格式 `CZYFK2-<密文>-<校验位>`

明文载荷：`2.<难度索引>.<实验项位图>.<车道数>.<模式标志>.<种子>.<分数>`

| 字段 | 内容 |
|---|---|
| 难度索引 | `easy/normal/hard/extreme/disabled` 对应 0~4 |
| 实验项位图 | 9 项按固定顺序打包成 base36：`flip/chaos/horror/ghost/multilane/reverse/barrage/titan/drift` |
| 车道数 | 多车道选了几道 |
| 模式标志 | bit0 实验大类 / bit1 命令模式 / bit2 出口模式 |
| 种子 / 分数 | base36 |

**加密与校验用同一套算法**（`CODE_KEY` 派生 FNV-1a + mulberry32 流加密）：

- 密文：逐字符按密钥流在 37 字符表上做模加
- 校验位：6 位；明文内部另带 4 位内层校验
- 改密文或校验位任意字符 → 提示「挑战码被改动过」，整份拒绝
- 前端单文件，密钥在源码里，防随手改与转发篡改，不是密码学级保密

导入路径：`挑战好友` / `种子` 页粘贴 → `applyCond()` 完整复现 → **跳过难度选择直接开局**。

### 1.3 等级码（不写在任何界面/文档）

5 段固定加密码，前缀同为 `CZYFK2-`，不出现在任何界面文字、更新日志或玩家文档里。输入后：

- 结算页显示「你距离该级别还有 XXX 分」
- 达标 → 海量金币 + 特别称号 + 专属编码（`CZYBD-…`）
- 每个存档同一级别只发一次
- 5 段码由开发者单独保管，不随项目文档分发

主界面「验证码」小功能可查验专属编码真伪、级别与称号。

### 1.4 极限装逼码 `CZYBB-JX-<加密分数>`

- 开发者模式与极限难度**都不能**导出对战挑战码（会连累对方存档）
- 极限局结算页生成装逼码，只能炫耀分数，不能开局
- 在「挑战好友」粘贴 → 显示「真实 / 伪造」与分数

### 1.5 老码兼容

`CZYFK-XX-种子-分数` 与 `FKCC-Q1:种子-分数` 仍能导入，按普通难度 + 对应大类复现；结算页写明「本码是老版挑战码，无法确定是否为真实的模式」。

## 2. 音乐：仅声音 / 声音+视频

设置里二选一（`save.settings.bgmAudioOnly`）：

| 模式 | 表现 |
|---|---|
| 仅声音 | 浮框收成 172px，iframe 变 1×1 不可见，只留标题栏控制条 |
| 声音+视频 | 原有 236px 可拖动浮框，显示 B 站播放器画面 |

B 站可能检测 iframe 不可见而暂停播放，仅声音模式不保证 100% 出声，需点框内一下。自定义音频直链仍走 `<audio>`。

## 3. 障碍教程、点消与「现」技能

### 3.1 箭头障碍（rush）

- 橙色倒三角，1.6 倍下落速度
- **连续点击箭头本体 3 下即消失**（本体上显示剩余次数）
- 首次出现弹一次教程，写存档不再重复
- 点本体优先，不误触发左右移动

### 3.2 防堵死

新增 `wouldBlockAll()`：生成时统计同屏障碍的车道并集，若会占满全部车道则退让为单块并落在已占用车道上，保证始终留一条活路。修复「箭头 + 双块墙把三条道全堵死」。

### 3.3 隐身方块（phase）与「现」技能

- 紫色方块周期性实体/虚化，虚化态可穿过
- 首次出现弹教程
- 右下角新增「现」圆圈，**CD 5 秒**：点一下让屏幕上所有隐身方块现身、0.5 秒逃跑动画后移除

## 4. 一车道通关玩法

多车道选 1 时不再是无法游玩的死局，改为点击消除：

| 障碍颜色 | 点击次数 | 得分 |
|---|---|---|
| 红 | 3 | 3 |
| 蓝 | 5 | 5 |
| 绿 | 10 | 10 |

- 障碍上显示剩余点击数；没及时点消就撞上失败
- 累计 **150 分通关** → 白色闪屏 → 宝箱界面 → 开箱获得 **+300 最高分 / 100 金币 / 隐藏皮肤「黄金」**
- 奖励每存档只发一次（`save.lane1Cleared`）

## 5. 商店与金币（测试版）

- 游戏中每隔 6~13 秒随机冒出金币，点击获得 1~5 金币，**PT 模式也能用**
- 设置 → 商店（测试）：4 件占位商品，花金币购买，仅作测试
- 金币写入存档，可在设置里查看余额

## 6. 账户 / 登录 / 后台管理

**玩家手册不写本节任何内容。**

### 6.1 登录（非强制）

- 主界面「账户」→ 昵称 + 密码登录或注册，可不登录直接玩
- 「个人主页」展示金币、最高分、专属编码、称号，并有一句固定提示语
- 获得的称号在主界面展示

### 6.2 后台（高级里的隐藏入口）

在高级命令输入框使用（不进命令书、不进玩家手册）：

| 输入 | 权限 |
|---|---|
| `admin-view` 或 `admin-pw devczy` | 只读查看 |
| `admin-edit` 或 `admin-pw cczzyyopen` | **一次全开修改权限**（本次会话） |

后台可：查看全部账户、增减金币（±100）、增减积分（±100）、新增/删除账户、导出/导入配置码。

**存档码保存**：别人把存档码发给你 → 打开后台 → 点列表里选中他的账户 → 把码粘进输入框 → 点「存档码保存」。系统会校验码有效后存到该账户记录里，方便后续增减。

## 7. 种子数字修复

`parseSeedInput()` 原本对所有非挑战码输入做 FNV 哈希，导致输入纯数字 `123` 变成另一串。现改为：

- 纯数字 → 直接当数值种子（`123` → 种子 123），超 32 位取模
- 保存原样显示标签 `seedDisplay`，HUD / 种子页 / 复制 / 结算统一用 `dispSeed()` 显示输入原文
- 非数字文本仍走哈希（大小写、符号原样保留的行为不变）
- 挑战码内部仍用 base36 数值种子，保证对局可复现
