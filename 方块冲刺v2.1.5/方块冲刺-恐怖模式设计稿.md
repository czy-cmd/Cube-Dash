# 方块冲刺 · 恐怖模式设计稿（kb-true / kb-false）

> 版本：v1.4.0 实现，**v1.5.2 重做**，v1.6.0 补充新系统交互
> 触发：高级命令 `kb-true` 开启；`kb-false` 或主菜单「退出」大按钮结束
> 定位：隐藏玩法，不在更新日志里写全（只留一句「高级里又多了点东西，自己敲敲看」）

---

## 1. 一句话设定

正常模式里那些盯着你跑的方块，其实是有意识的。
恐怖模式就是把这层「它们只是障碍物」的伪装撕开——一旦开启，游戏不再只是跑酷，而变成一场被注视的审讯。

---

## 2. 核心原则：它是「会话模式」，不是「一局 buff」（v1.5.2 重做）

v1.4.0 / v1.5.1 里，恐怖模式太容易结束了：死一次、点一下结局页，甚至回主菜单，血红界面就没了。
玩家反馈「没有我想的好」「应该持续到玩家点击退出，一整局游戏全是恐怖！大恐怖！」。

因此 v1.5.2 把它改成**贯穿整个游玩会话的状态**：

```
kb-true ──► 开启（血红界面常驻）
            │
            ├── 开局 ──────► 整局大恐怖（跳过难度选择）
            ├── 死亡 ──────► 结局质问页（恐怖高潮，不弹普通结算）
            ├── 轻触结局 ──► 回主菜单，仍是血红
            ├── 再开一局 ──► 仍是恐怖，且仍是纯恐怖速度
            └── ……循环……
            │
点「退出」或 kb-false ──► 结束，界面恢复正常
```

- **只有两个出口**：主菜单「退出」大按钮、`kb-false`。中途死亡 / 回菜单 / 再开局都**不中断**恐怖。
- `resetExp()`、`refreshMenu()`、结局页关闭都**不再清** `horrorStory`（v1.5.1 只修了前两个）。
- 统一收尾函数 `endHorror()`：清 `horrorStory`、结局页、独白、`--hgloom` 血雾变量、血色界面。
- 恐怖模式开局时强制 `curDiff='normal'`：上一局的「极限删档」「残疾延迟」不会串进恐怖局。

## 3. 分层效果（v1.5.2 已落地）

| 阶段 | 表现 | 实现 |
|---|---|---|
| 开启瞬间 | 界面切到血红；菜单按钮、面板、标题、分数全部血色；暗角加深、扫描线出现 | `applyHorrorVisual()` → `body.blood` + `#horror`；`.blood .btn/.panel/h1/#score` |
| 全程（呼吸） | 血色暗角 3.1s 缓慢呼吸，扫描线持续流动，不会停 | CSS `@keyframes hvig` / `hscan` |
| 全程（渐浓） | 血雾随存活时间从 `.72` 逐渐压到 `.98`，越玩越红、越闷 | `update()` 写 `--hgloom`，暗角 `rgba(120,0,0,var(--hgloom))` 读取 |
| 全程（心跳） | 低频心跳音，间隔随存活时间从 1.5s 缩短到 0.45s，越到后面越急 | `G.heartT` + `sfx('heart')` |
| 全程（视觉） | 障碍**恒为血红**（不再 50% 概率闪），暗红为主、偶发亮红；眼睛血红、**永不眨眼**，一直盯着你 | `render()` 内 `if(horrorStory)obsColor=…`；`drawEyes()` 内 `blink=!horrorStory` |
| 全程（独白） | 自我怀疑独白几乎不断：前期 3.6~5.8s 一句、显示 3s；第 4 波起 2.6~4.2s 一句、显示 2.3s，并换成更瘆人的后期台词 | `G.horrorT` + `horrorLine()` + `#horrorText` |
| 间歇（黑屏） | 独白时 60%（后期 85%）概率黑屏闪；另有独立的 5~9s 黑闪计时 | `darkFlash()` |
| 死亡瞬间 | 所有方块停下，三个巨大血红眼睛睁开，血光背景与瞳孔持续脉动，下方浮现质问 | `#horrorFinale` + `@keyframes hfinale` / `heyepulse` |
| 结局之后 | 轻触结局层 → 回主菜单，**恐怖继续**；没勾「死亡定格背景」则清干净画布 | `closeHorrorFinale()` |
| 结束 | 点「退出」或 `kb-false` → 血红界面、独白、结局页、血雾变量一并清除 | `endHorror()` |

## 4. 自我怀疑语句池

### 前期（HORROR_DOUBT）

- 你按下的每一个方向，都是别人写好的。
- 这些方块，真的在被你躲开吗？
- 还是你只是在重复一段已经发生的录像？
- 分数有什么用。没人会记得。
- 你为什么还在玩？
- 它记得你。你却不记得它。
- 那个退出按钮下面，藏着它不想让你看见的东西。
- 如果方块停下来，你敢看它们的眼睛吗？
- 别回头。菜单一直在这，可你回不去了。
- 屏幕外面，有东西在数你还剩几次。

### 后期（HORROR_LATE，第 4 波起）

- 已经第 N 波了？我数不清了，你呢。（`N` 运行时替换为真实波次）
- 它们不眨眼了。从什么时候开始的？
- 你刚才那一下，是躲开了，还是被放过去了？
- 血是从屏幕里渗出来的。擦不掉的。
- 别停。停下来它们就赢了。
- 这一局没有终点。只有你先眨眼。
- 你确定现在还握着方向键吗？
- 我一直在看着你。从你打开这个页面开始。

设计意图：每一句都在瓦解「玩家是主体、方块是客体」的错觉。前期是怀疑，后期是确认——**它已经在这里了**，为结局的「反客为主」铺垫。

## 5. 结局叙事（重点）

死亡的瞬间，游戏不再用「游戏结束 + 贴纸分数」那一套。取而代之：

1. 世界静止。背景压成近黑的红，血光缓慢起伏。
2. 三双眼睛从黑暗里睁开——不是笑，不是凶，是「困惑地看着你」，瞳孔一收一放。
3. 它们问出那句话：**「我……是谁？为什么存在？」**
4. 小字补一句环境描写，把「被注视」的寒意坐实。
5. 玩家轻触屏幕，眼睛闭上，回到主菜单——**但界面还是血红的，它们没走**。你只能再开一局，或者去按那个「退出」。

这句话刻意不回答。方块没有身世、没有答案——它只是在用临死前的最后一眼，把「存在」这个问题抛回给一直在操控它的人。
而 v1.5.2 的关键改动是：**这一眼之后，恐怖不结束**。以前点一下就恢复正常，像什么都没发生；现在你还得带着这一眼继续玩下去。

## 6. 与现有机制的关系

- 复用「实验性玩法 → 恐怖画风（blood）」的视觉底层，不另起炉灶；两者可叠加，互不覆盖。
- 不影响挑战码、不计分规则、存档（恐怖仍是**会话状态**，刷新页面即消失，不写存档）。
- 死亡时**不弹普通结算页**（`gameOver()` 在恐怖分支直接 `return`），所以看不到分数与挑战码——这是刻意的：结局不属于计分系统。
- 开发者模式 / 电脑模式 / 慢放技能照常工作，可以叠加。
- 跳过难度选择：恐怖模式不弹 MC 式 5 难度，也强制普通速度，避免「极限删档」把存档带走。
- **「死亡定格背景」设置项现在真正生效**（见第 7 节）。
- 故意不写进更新日志正文，只留一句隐晦提示，作为给玩家的「自己摸索」空间。

## 7. v1.5.2 修掉的 bug：没开死亡定格却仍然定格

设置里的「死亡定格背景（返回菜单保留上一局画面）」由 `keepDeathBg` 控制，`loop()` 的逻辑是：

```js
if(state!=='menu'){render();menuCleared=false;}
else if(!menuCleared){menuCleared=true;if(!save.settings.keepDeathBg)clearCanvas();}
```

**根因**：恐怖死亡走的是 `horrorFinale` 结局页，而结局页的点击处理**漏了把 `state` 复位成 `'menu'`**（普通结算的「返回主菜单」按钮是有的）。于是 `state` 一直停在 `'over'`，`loop()` 每帧都走第一分支持续重绘死亡瞬间的冻结画面，并把 `menuCleared` 反复置为 `false` —— `clearCanvas()` 永远不会执行。结果：即使没勾「死亡定格背景」，回菜单后画面也一直定格，这个开关在恐怖模式下完全失效。

**修复**：`closeHorrorFinale()` 里补 `state='menu'` 与 `menuCleared=false`，保证下一帧一定走一次回菜单判断；没勾就清屏，勾了才保留画面。

## 7.1 v1.6.0 新系统下的恐怖模式（补充）

本版新增的障碍、摇杆、切道动画、皮肤、音乐、实验性玩法都不改变第 2 节的「会话模式」原则，但有几处交互需要明确：

| 新系统 | 与恐怖模式的关系 |
|---|---|
| 4 种新障碍 | 恐怖模式下 `render()` 优先把**所有**障碍染成血红（原逻辑在 `ot.color` 之后覆盖），所以巨墙 / 急坠 / 相位 / 追踪各自的专属颜色会被压掉，保证「一整局全是恐怖」。行为（相位虚化、追踪平移、急坠加速）照常生效 |
| 相位障碍 | 虚化态仍可穿过，但在恐怖模式下虚线描边也是红色——看起来像「它放你过去」，叙事上更瘆人 |
| 摇杆模式 | 完全独立。开摇杆只改操控方式，不影响恐怖状态；摇杆区域仍被点屏判定排除 |
| 切道动画 / 尾光 | 尾光固定用青色渐变绘制，不受 `blood` 影响；恐怖模式下仍是一条冷色拖影，与血红背景形成反差。判定依旧走 `G.lane` |
| 皮肤系统 | **只改玩家方块**，不会覆盖恐怖模式的障碍血红、血雾暗角、独白与结局页。自定义皮肤可与恐怖模式叠加 |
| 背景音乐 | 互不干扰。恐怖模式不会强制开/关音乐；玩家想配 BGM 需自己在设置里开 |
| 3 项新实验玩法 | 恐怖模式跳过难度选择并强制 `curDiff='normal'`，但 `expFlags` 不清除，`barrage` / `titan` / `drift` 照常生效。注意 `titan` 会让整局全是巨墙，恐怖氛围下压迫感极强 |
| 关于页彩蛋 | 与恐怖模式无关，独立解锁隐藏皮肤 |

> 设计约束：恐怖模式的视觉统一性（第 2、3 节）优先级高于任何新障碍/新皮肤的专属配色。以后加新视觉元素时，都要先判 `horrorStory` 再上色。

## 7.2 v2.1.5 补充

| 新系统 | 与恐怖模式的关系 |
|---|---|
| 挑战码条件复现 | 恐怖模式下 `requestStart` 会跳过难度并强制 `curDiff='normal'`；但 v2.1.5 起导入路径直接调 `startGame()`，不再经过 `requestStart`，所以挑战码里的难度**不会被恐怖模式覆盖**。注意：若玩家自己开着恐怖模式再导入挑战码，画面仍是血红（会话模式规则），这属于玩家自身状态，不受挑战码控制 |
| 音乐仅声音 | 与恐怖氛围无关，独立开关 |
| 教程 / 现技能 | 首次出现箭头或隐身方块时 `showTip()` 会暂停游戏；恐怖模式下教程层同样显示，不破坏恐怖状态 |
| 一车道 / 商店 / 金币 | 金币是 DOM 层（z-index 36），在血雾层之上，恐怖模式下仍可点击 |
| 等级码 / 账户 | 与本设计稿无关；主界面称号展示、个人主页均为独立层 |

> 约束不变：恐怖模式的视觉统一性优先于任何新障碍/新皮肤配色。

## 8. 后续可扩展（未做，留待 v3.0 或之后）

- 结局后解锁一段「方块视角的第一人称」彩蛋关。
- 自我怀疑语句随死亡次数递增、变本加厉（目前只按波次切换）。
- 真正的「多结局」：根据是否曾开过无敌、是否用过慢放，给出不同质问。
- 触摸结局页的眼睛会触发反转（玩家被方块「选中」）。
- 恐怖模式下点「退出」时，让再见页多留一句台词。
