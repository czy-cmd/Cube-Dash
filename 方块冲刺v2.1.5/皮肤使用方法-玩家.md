# 方块冲刺 · 皮肤使用方法（玩家版）

> 版本：v1.6.0
> 入口：主菜单 → 设置 → **自主设置皮肤**
> 原始格式说明：同目录《皮肤的使用方法.txt》

---

## 1. 能做什么

皮肤代码**只改变玩家方块的外观**。障碍、背景、网格、HUD 不变。

两种模式：

| 模式 | 声明 | 效果 |
|---|---|---|
| `normal` | `size = normal` | 整个玩家方块填成一种纯色 |
| `pro` | `size = pro` | 把玩家方块切成 `w × h` 个像素格，逐格上色 |

支持粘贴文本导入，**不支持导入 .txt 文件**。导入结果写入存档，换浏览器可用「存档码」备份。

---

## 2. 格式速查

- `#` 是注释：写在行首，或写在语句后面（前面带空格）。`#RRGGBB` 里的 `#` 不会被当注释。
- 空格可有可无，`size=normal` 与 `size = normal` 都行。
- 每行一条语句；语句不认识会报错并标出行号。

### 语句表

| 语句 | 作用 | 适用 |
|---|---|---|
| `size = normal` / `size = pro` | 声明模式，**必须写，且只能写一次** | 全部 |
| `size.color(x)` | 设置纯色 | normal |
| `size.x_y(w,h)` | 像素网格宽、高，各 1~16 | pro |
| `size.pro.名字 = [` | 开始定义一个像素表，名字自己起 | pro |
| `[[red],[green],[blue]],` | 像素表的一行，每格一个颜色 | pro |
| `]` | 结束像素表 | pro |
| `use(size.pro.名字)` | 指定使用哪个像素表，**必须写** | pro |

### 颜色怎么写

1. **十色名**（不区分大小写）：`red` `orange` `yellow` `green` `cyan` `blue` `purple` `pink` `white` `black`
2. **RGB 三参数**：`255,0,128`（每个 0~255）
3. **十六进制**：`#FF00AA`
4. **空格** `[]`：该格透明，露出下方背景

## 3. 可直接复制的示例

### 3.1 normal 纯色（红）

```
size = normal
size.color(red)
```

换成任意颜色：

```
size = normal
size.color(255,0,128)
```

或

```
size = normal
size.color(#FF00AA)
```

### 3.2 pro 像素画（3 宽 × 2 高）

```
size = pro
size.x_y(3,2)
size.pro.mine = [
[[red],[green],[blue]],
[[255,255,255],[100,203,102],[]]
]
use(size.pro.mine)
```

效果：上排红 / 绿 / 蓝，下排白 / 自定义青绿 / 透明。`mine` 可以改成任意英文名。

> 提示：原始格式说明里第三行 `[[#你应该可以根据上面的两种推断出来了],[],[]]` 是**占位说明**，不是合法代码。真实输入请写成颜色名、`R,G,B`、`#RRGGBB` 或 `[]`。
> 同理 `size = somethings`、`size.x_y(x,y)`、`size.color(x)` 里的 `somethings` / `x` / `y` 都是占位，要换成实际值。

## 4. 导入步骤

1. 设置 → **自主设置皮肤**，打开独立界面。
2. 在下方多行输入框粘贴皮肤代码。
3. 点 **导入并应用**。
4. 绿色提示 = 成功；红色提示 = 失败，**列出所有问题，每条都带「第 N 行」**。
5. 失败时**整份拒绝**：不会应用一半、也不会留下半成品。按提示改完再导入一次。
6. 想还原：点 **恢复默认**（回到霓虹配色 + 默认玩家方块）。

界面上方的列表可切换内置配色：霓虹（默认）、黄金（隐藏，见下）。自定义皮肤与内置配色可叠加。

## 5. 常见错误

| 提示 | 原因 |
|---|---|
| `皮肤代码为空` | 输入框什么都没填 |
| `缺少 size = normal 或 size = pro 声明` | 没写 mode，或写成了 `somethings` 之类的占位 |
| `normal 模式缺少 size.color(...)` | normal 没给颜色 |
| `pro 模式缺少 size.x_y(w,h)` / `缺少 use(...)` | pro 少写必备语句 |
| `use 引用了不存在的像素表：xxx` | `use` 的名字和 `size.pro.名字` 对不上 |
| `像素表 xxx 有 2 行，但 x_y 要求 3 行` | 行数与 `h` 不符 |
| `第 N 行：有 2 格，但 x_y 要求 3 格` | 某一行的格子数与 `w` 不符 |
| `第 N 行：第 k 格颜色无效「…」` | 颜色名拼错、RGB 超出 0~255、或写了占位文字 |
| `像素表 xxx 缺少结束的 ]` | 忘了单独一行写 `]` |
| `第 N 行：无法识别的语句「…」` | 拼写错误、多了括号、或残留示例占位文字 |
| `x_y 宽高须为 1~16` | 网格太大或为 0 |
| `size 重复声明` / `size.color 重复` / `像素表 xxx 重名` | 同一语句写了两遍 |

## 6. 隐藏皮肤

关于页面那个**黄色版本号标签**，在 1.8 秒内连续点 **5 次**，解锁「黄金」皮肤。解锁写入存档，之后可在皮肤列表里切换。已解锁再点只会提示，不重复。

---

## 7. 说明

- 皮肤只影响外观，不影响碰撞、分数、挑战码、最高分。
- 开发者模式下的黄色判定框始终画在逻辑车道，可用来确认动画/皮肤不干扰判定。
- 极限难度死亡会永久删档，皮肤、解锁状态会一起清空。
