一、动手之前，先记住这六条
================================================================================
1. 所有命令效果只在「本次页面会话」有效。刷新页面 = 全部恢复默认。
   不写进存档，不污染 localStorage。

2. 唯一不能导出挑战码的情况：开发者模式开启（devLevel > 0）。
   实验性玩法、出口模式、percent、url 任务现在都能导出，只是挑战码
   开头两位字母不同。

3. 不写进 highScore 的范围比上面宽：实验性玩法或任意高级命令生效时，
   本局成绩都不记最高分，但挑战码照常给。totalGames / totalDodged 照常累加。
   结算页会写明「本局不记最高分，仍可发挑战码」。

4. 通过挑战码进行的对战不改变原有设置：导入只设置种子和对手成绩，
   不会清掉你的实验开关、出口模式、percent、url 任务、音效等任何设置。

5. 命令大小写不敏感；密码大小写敏感（v1.2.0 已修）。
   命令输错只回 unknown command，不改任何状态。

6. 密码写在单文件 HTML 里，而完整开发者模式能查看整页源码。
   所以密码只是防误触，不是安全措施。别拿它当真密码，也别复用。

「高级」和「实验性玩法」是两个独立入口、两个不同的警告框，互不隶属。

二、进入流程
================================================================================
主菜单「高级」
  → 警告框「确定要进入吗？」
  → 点「确定」，出现一个普通单行输入框 + 实体「Enter」按钮
  → 输入命令，点 Enter
  → 屏幕颤动约 0.34 秒
  → 黑屏 1~2 秒
       黑屏上会用打字机逐字打出一句英文自我怀疑，带闪烁光标，例如：
         Am I still me?
         Who pressed left just now?
         The block moved. Or did I?
         Something is typing this. Not me.
  → 显示反馈：XXX is turn on,and you can XXX.
       （句式按原始设定保留，is turn on 的语法不改）
  → 若开启的是开发者模式，主菜单会多出一个原本隐藏的按钮

从主菜单直接进「高级」是支持的，不需要先开一局。

三、命令总表
================================================================================
【1】get 家族
--------------------------------------------------------------------------------
get from enter
    打开「出口实验性功能」。游戏目标从刷分变成走出出口。
      门槛序列：100 / 500 / 1000 / 2000 / 4000 / 8000 ……
                前三档固定，之后每档 ×2，没有终点。
      出口形态：单车道发光门框，随障碍一起逼近；
                不碰撞、不阻挡、不计擦边。
      判定：门经过玩家 Y 平面时，玩家在该车道 = 走出成功。
      错过：可在同一门槛重试（每 3~5 秒再来一次），不推进、不惩罚。
      安全：门前后各 1 秒不生成障碍，门所在车道不放障碍。
      通关：只给特效和提示，不给数值奖励；撞到障碍照常死亡。
      门槛按真实分数判定，不受「分数乱动」显示层影响。
      HUD 右上角会显示「目标：走出出口 / 下一个：XXX 分」。
      本局挑战码前缀为 CM。

get from in
    开发者模式「阉割版 A」：文字调试信息 + 碰撞盒可视化。
    游戏中显示：FPS、dt、seed、lane、障碍数、elapsed；
    画布上用黄框画出玩家与障碍的真实判定盒（80% 大小）。

get from percentN
    N 是 0~100 的整数，必须连写、不加空格。
    例：get from percent40 → 只保留约 40% 的功能入口。
    规则：按固定功能清单顺序保留前 N%，可复现、好调试。
    被关掉的功能「入口仍然在」，点进去显示独立的 404 网页（见第五节）。
    白名单（永远不会被砍）：设置 / 高级 / 实验性玩法 / 关于 / 更新日志。
    所以 percent0 也不会把自己锁死。刷新页面恢复 100%。
    本局挑战码前缀为 CM。

get into dev
    开发者模式「阉割版 B」：阉割版 A 的全部权限 + 控制生成。
    新增按钮：下一波 / 开无敌·关无敌 / 清障碍。

get into pro
    屏幕爆闪一下，然后什么也不给。
    纯彩蛋，没有「超级模式」，不会进入任何特殊状态。

【2】url- 家族
--------------------------------------------------------------------------------
url-<网址>
    立即打开网址。没写 http:// 或 https:// 时自动补 https://。
    例：url-example.com

url-<网址>-t N
    延迟 N 秒后打开。N 的单位是秒，例：url-example.com-t 10
    关掉「高级」面板不影响任务，到点照样执行。
    关掉网页 / 刷新页面 → 任务消失（JS 停了，物理上做不到继续执行）。
    iOS Safari 大概率拦截自动弹窗。被拦时页面底部会出现
    「到点了：点此打开网址」的可点按钮，点它才跳。

url-None
    取消所有尚未执行的 url 任务。

【3】type 家族
--------------------------------------------------------------------------------
type on <密码>
    开启无任何阉割的完整开发者模式（等级 3）。
type off <密码>
    关闭开发者模式，并顺带复位出口模式与 percent。
    注意：它不会清掉 url 任务，请用 url-None。
    密码大小写敏感，必须写 devczy。

四、开发者模式：现在是一个原本隐藏的按钮
================================================================================
v1.2.0 起，主菜单上有一行默认不显示的「开发者面板」按钮。
只要开发者等级 > 0，这行才出现；点它打开一个独立的开发者面板。

  · 主菜单不会冒出一大块区域，只有一个按钮 —— 这是你要的形态。
  · 高级面板本身不再展开任何开发者内容。
  · 开发者面板里才有：等级说明、功能按钮、「代码源码」、返回。

--------------------------------------------------------------------------------
等级   触发命令              实际权限
--------------------------------------------------------------------------------
 1     get from in           文字调试 HUD + 碰撞盒线框
 2     get into dev          等级 1 + 下一波 / 开无敌·关无敌 / 清障碍
 3     type on devczy        等级 2 + 以下全部
--------------------------------------------------------------------------------

等级 3 的按钮：
    +100 分          改本局分数
    404 页面         打开独立的 404 NOT FOUND 网页
    内部页面         一个写着「这里本来应该有很多东西」的彩蛋页
    配色切换         在霓虹 / 酸橙 / 冷蓝三套配色间循环
    存档 +1000       真的把 highScore 加 1000（会污染纪录，别拿去炫耀）
    代码源码         双层隐藏，见下

「代码源码」按钮的双层隐藏条件：
    第一层：整块开发者面板要能进（devLevel > 0）
    第二层：devLevel >= 3 且系统是 Windows 才显示
    结果：iPhone 上这个按钮永远不出现，其余开发者权限照常可用。

「代码源码」里能做什么（仅 Windows）：
    · 执行任意 JS —— 等于拿到整个游戏和 localStorage 的修改权
    · 查看整页源码 —— document.documentElement.outerHTML
    · 复制源码 —— 复制失败时会自动选中文字，不再假装「已复制」

五、404 页面
================================================================================
v1.2.0 起，404 不再是一行文字，而是一个单独的网页层：
    顶部是仿浏览器地址栏（假域名 block-dash.local）
    中间是大号 404 + 「404 NOT FOUND」
    底部一个「返回游戏」按钮
    浅灰底，和游戏的霓虹黑底刻意反差
    不联网、不离开页面，会话状态不丢；游戏中触发会先冻结，返回后继续

触发方式：
    · get from percentN 砍掉功能后，点菜单里那个保留着的入口
    · 开发者面板的「404 页面」按钮
    · 内部页面里的「打开 404 页面」按钮

六、挑战码（v1.2.0 新格式）
================================================================================
统一格式：CZYFK-XX-种子-分数
    种子、分数都是大写 base36，例：CZYFK-PT-1FLGQIH-5

开头两位字母标出本局模式：
--------------------------------------------------------------------------------
  PT   普通模式                        ← 你说的「仅普通模式展示」就是它
  EX   开启任意实验性玩法
  CM   高级命令生效（出口 / percent / url），且没开实验
  MX   实验性玩法 + 高级命令同时生效
  DV   开发者模式 —— 不生成挑战码；手工输入这种码会被拒绝
--------------------------------------------------------------------------------

三条规则（按你的要求实现）：
  1. 开发者模式是唯一不能导出挑战码的情况。
     实验局、出口模式、percent、url 任务都照常给码。
  2. 通过挑战码进行的对战不改变原有设置。
     导入只写 challengeSeed 与对手成绩，不清实验开关、不清命令状态、
     不重置任何设置项。
  3. 所有码统一以 CZYFK- 开头，第二段的两个字母随模式变化。

兼容与限制：
    · 旧的 FKCC-Q1:种子-分数 仍能导入，但以后只生成 CZYFK- 格式。
    · 存档码是 FKCC1: 开头的 base64，和挑战码不是一回事。
    · 前缀只做标记，导入时不会把对方切到你的模式。
      也就是说：不同模式的人拿同一串码，跑的是同一串障碍，
      但规则可能不同（比如一个人开了重力翻转）。这是按你的要求
      放宽了公平性，比较时自己留意开头两位字母。
    · 前缀两位字母可以是任意两个大写字母，都能导入；DV 除外。

哪里能拿到码：
    · 结算页（自动生成，带「复制挑战码」）
    · 主菜单「种子」→「生成挑战码」（不用先死一局）

七、设置里的「死亡定格背景」
================================================================================
设置面板多了一个开关，默认关闭。

  关闭（默认）：返回主菜单时清掉画布，恢复纯净黑底，和首次打开一致。
  开启：返回主菜单时保留上一局死亡那一帧，菜单按钮叠在画面上。
        这就是你截图里看到的那个效果，现在它是一个正式功能。

  它写进 settings.keepDeathBg，属于存档的一部分，会跟着存档码走。

八、怎么恢复 / 复位
================================================================================
按代价从低到高：
  1. 结算页点「关闭开发者模式，用这个种子重开」
     只在开发者模式生效时出现，一键关掉开发者模式并用同一种子重开。
  2. 刷新页面
     所有高级效果、url 任务、实验开关全部恢复默认。最彻底。
  3. 命令复位：type off devczy
     关开发者模式，顺带复位出口模式和 percent；url 任务另用 url-None。
  4. 主菜单「种子」或「挑战好友」里开局
     这两条路径只设置种子，不会改动你的任何设置。

补充：从结算页「返回主菜单」会自动清空实验性玩法的勾选
（每局勾选、下局恢复默认关），但不会动设置项。

九、常见问题
================================================================================
Q：输完命令黑屏不恢复？
A：v1.0.1 已修（顶层初始化随机数 + 恢复回调加防御）。
   如果线上还是旧样子，强制刷新一次清缓存。

Q：结算页没有挑战码？
A：现在只可能是开发者模式开着。结算页会写明原因，并给
   「关闭开发者模式，用这个种子重开」按钮。
   实验局和高级命令局都能出码，只是前缀是 EX / CM / MX。

Q：为什么结算页写着「不记最高分」，却还有挑战码？
A：这是两件事。记不记最高分看有没有实验/命令生效；
   能不能发挑战码只看开发者模式。分开的，不是坏了。

Q：菜单里点某个入口跳 404？
A：get from percentN 砍功能时故意保留入口，点进去是独立的
   404 NOT FOUND 网页。点「返回游戏」回来，或刷新页面恢复 100%。

Q：url 任务到点了没跳转？
A：看页面底部的「到点了：点此打开网址」按钮，iOS Safari 会拦自动弹窗。
   关掉网页后任务不会继续执行。

Q：密码忘了 / 想改？
A：devczy，大小写敏感。它写在源码的 CONFIG.devPassword 里。
   改完要重新发布线上版本才会生效；本地文件双击打开则立即生效。

Q：开发者模式能拿高分吗？
A：能改本局分数甚至改 highScore，但开发者模式生效期间不写最高分、
   不发挑战码。手动用「存档 +1000」改的纪录是假的，别拿去跟朋友比。

十二、v1.3.0 新增
================================================================================
（一）第 3 波教程
    进入「第 3 波 · 三连窄缝」时游戏自动暂停，弹「要开教程吗？」。
    选「开启教程」后分步讲三件事：①左右半屏切道 ②贴边擦过攒倍率
    ③慢放技能。讲完点「开始」继续。每局只弹一次，选「跳过」则不再弹；
    不影响实验性玩法 / 挑战对战，只是个提示层。

（二）慢放技能（第 3 波解锁）
    右下角出现一个「慢」小圆圈。点一下，整个世界变 0.5× 持续 4 秒，
    趁机去点（触屏点 / 电脑点鼠标）障碍，把它直接消掉。
    普通模式冷却 10 秒（从触发起算，圆圈上显示剩余秒数）；开发者模式无冷却。
    开发者模式也走这个圆圈放技能，只是不进冷却。

（三）无敌改成小圆圈（仅开发者可见）
    开发者模式（devLevel > 0）时左下角出现「无」小圆圈：点一下本局一直
    无敌，再点一下关闭——本局内永久 toggle，开局重置，不写存档。
    原来开发者面板里的「开/关无敌」按钮已移除（那是个有 bug 的按钮）。

（四）电脑模式（设置里新增开关）
    打开后键盘也能玩：Q = 慢放、P = 无敌、A / D 也能控制方向。
    不打开时，只有方向键（← →）与空格（开始/重开）生效，
    A / D 不生效，Q / P 也不生效——避免误触。
    手机上开不开都没影响，全靠点。

（五）实验性玩法面板文案已修正
    旧文案写「也不能生成挑战码」，现已改为：仍不记最高分，但能导出
    挑战码（前缀 EX）。这是 v1.2.0 规则（只有开发者模式禁导出）落地时
    漏改的一处静态提示，游戏内结算逻辑一直是对的。
