# 方块冲刺 · 高级功能 玩家使用手册

> 版本对应：v2.1.5（设计 v2.6）
> 本手册只讲「普通界面之外」的进阶玩法。基础操作（点屏幕左/右半区移动、擦边攒倍率）请看游戏内说明。

---

## 0. 这些功能在哪

主菜单点 **高级** → 弹窗点 **确定** → 出现输入框，输入命令后按回车（或点 Enter）。

- 命令不区分大小写。
- 空格和连字符 `-` 大部分情况通用（例如 `tp 5` 与 `tp-5`、`tp 3 next` 与 `tp-3-next` 等价）。
- 这些命令分两类：**永久/会话级**（写入或影响存档）和 **本局级**（只影响当前这一局）。下面会标清楚。

---

## 1. 五档难度（进游戏先选）

每次从「开始游戏 / 实验性玩法 / 种子 / 挑战好友」进入一局时，会先弹 **选择难度**（模仿 MC）。这是 v1.5.0 新增。

| 难度 | 速度倍率 | 说明 |
|------|---------|------|
| 简单 | ×0.8 | 慢一点，好上手 |
| 普通 | ×1.0 | 标准 |
| 困难 | ×1.2 | 快一点 |
| 极限 | ×1.3 | 见下方「极限规则」，**需二次确认** |
| 残疾 | ×0.7 | 见下方「残疾规则」，**需二次确认并说明** |

- **简单/普通/困难**：只改整体速度，其它照旧。
- **二次确认**：点 极限 或 残疾 后会弹出说明，要连点两次「我确定」才生效（防止手滑）。
- **再来一次**：不重新弹难度，沿用上一局选的难度。
- **恐怖模式（kb-true）下不弹难度**，直接按恐怖流程进，并强制普通速度（不沿用上一局难度）。

### 极限规则（死亡永久删档）
- 本局一旦 **死亡**，本地存档会被 **永久删除**：历史最高、总局数、设置全部清空，不可恢复。
- 出口分数变为 **300 / 600 / 900 / 1200 …**（普通模式是 100/500/1000）。
- 结局 highscore 按 **3 倍** 计入——但只有你 **主动返回主菜单退出本局（不算死亡）** 时才会保留这 3 倍纪录；死亡则一切归零。
- 一句话：**要么见好就收把 3 倍带走，要么赌一把，死了全没。**

### 残疾规则
- 游戏速度变成 **0.7×**（第三波额外再 ×0.5，更慢）。
- 你的 **每一次点击会延迟 1~3 秒才执行**，方块可不会等你。
- 适合想体验「手脑脱节」折磨感的玩家。

## 2. 命令速查表

下面把所有命令列出来。**带「会话/永久」标注的会影响存档或跨局；其它只影响当前游戏。**

### 2.1 模式与系统命令
| 命令 | 作用 | 性质 |
|------|------|------|
| `get from enter` | 开启 **出口模式**（跑到出口格子得分） | 本局 |
| `url-网址 [-t 秒]` | 到点自动打开网页；`url-none` 关闭 | 本局 |

> **开发者模式相关的命令**（`type on/off devczy`、`get in` / `get into dev` / `get into pro`、`get from percent N`、隐藏页/源码页等）属于维护与调试用途，**本手册不讲**，统一放在《方块冲刺-高级功能-开发者使用手册》里。

### 2.2 恐怖模式（会话模式，v1.5.2 重做）
| 命令 / 操作 | 作用 |
|------|------|
| `kb-true` | 开启 **恐怖模式**：整段游玩全程血红，直到你主动点「退出」 |
| `kb-false` | 提前关闭恐怖模式 |
| 主菜单「退出」大按钮 | 结束恐怖（不点了就一直是恐怖） |

**它不是一个「一局 buff」，而是贯穿整个会话的状态**：开启后，开局、死亡、回主菜单、再开一局，全程都是恐怖，中途不会中断。只有上面两个出口能结束它。刷新页面也会消失（不写存档）。

开启后的表现：菜单/按钮/标题/分数全变血色；血雾暗角持续呼吸并随存活时间越来越浓；心跳越来越急；自我怀疑独白几乎不断，第 4 波起换成更瘆人的台词；障碍与眼睛恒为血红，眼睛不再眨眼；死亡时不弹普通结算，而是方块停下、三双血红眼睛质问「我……是谁？为什么存在？」——**轻触结局页回到菜单后，界面仍是血红的，它们没走**。

> 注意区分两个「恐怖」：
> - 实验性玩法里的 **恐怖画风**（勾选 `horror`）只是视觉变血红，没有剧情，且只作用本局。
> - `kb-true` 才是完整 **恐怖模式**（含剧情与结局），且它是命令，不在实验性勾选里。
>
> 恐怖模式**不弹难度选择**，并强制普通速度，不会把「极限删档」「残疾延迟」带进来。
> 设置里的「死亡定格背景」在恐怖模式下也正常生效：没勾就回菜单清干净画布，勾了才保留上一局画面。

### 2.3 跳波命令 `tp`
| 命令 | 作用 |
|------|------|
| `tp N` | 立即跳到第 `N` 波 |
| `tp N next` | 下一次「波次变化」后跳到第 `N` 波 |
| `tp N M.ago` | 再经过 `M+1` 次波次变化后跳到第 `N` 波（例如 `tp 8 3.ago` = 4 次变化后到第 8 波） |

- 连字符也支持：`tp-5`、`tp-5-next`、`tp-5-3.ago`。
- `tp` 只能在 **游戏进行中** 用（没开局会提示你先开始）。

### 2.4 `about` 四件套（元命令）
| 命令 | 作用 | 性质 |
|------|------|------|
| `about-things` | 把一次 **永久操作** 写入存档（`save.aboutThings` 计数 +1，不会消失） | **永久** |
| `about-choose` | 本会话结局 **不写入存档**（再输入一次关闭）——适合想随意试玩不留痕迹 | 会话 |
| `about-command` | 进入 **命令模式**：主界面变成冰冷输入框，附一本列出所有命令的「书」，没有教程 | 本局 |
| `about-game` | 取消主界面，**直接开始游戏** | 本局 |

> 另有 `about-use` 是调试命令（返回各模式/难度/种子构建 log），属开发者向，详见《方块冲刺-高级功能-开发者使用手册》。

## 3. 命令模式（about-command）

输入 `about-command` 后，主菜单会被一个冰冷的输入框取代：

- 没有按钮、没有提示，一切靠命令。
- 点 **书** 会展开一列已知命令（就是上面第 2 节的那些），但 **不给教程**——你自己试。
- 想进游戏就输入 `about-game`；想离开就点 **离开** 回主菜单。
- 在命令模式里直接敲 `get`/`tp`/`kb-true` 等同样有效，只是没有黑屏动画。

## 4. 实验性玩法（主菜单 → 实验性玩法）

勾选后本局 **不记入最高分**（但仍能生成挑战码，前缀 `EX`）。开启后本局无法关闭。

| 开关 | 效果 |
|------|------|
| 重力翻转 `flip` | 左右方向相反 |
| 分数乱动 `chaos` | 分数会乱跳（结算有彩蛋） |
| 恐怖画风 `horror` | 视觉变血红 |
| 幽灵方块 `ghost` | 多出一个幽灵方块 |
| 多车道 `multilane` | 进入时弹窗，点 1~10 选车道数（不用输入） |
| 倒车模式 `reverse` | 障碍反向而来 |
| 密集弹幕 `barrage` | 所有障碍生成间隔 ×0.62，明显更密 |
| 巨墙模式 `titan` | 每个障碍都是横贯跑道、只留一道缝的巨墙 |
| 漂移惯性 `drift` | 切道视觉会冲过头再回正，仅影响画面 |

> 同时勾选多个 + 用命令，模式码会变成 `MX`（混合）。
> 后 3 项是 v1.6.0 新增，逐项说明与组合效果见《方块冲刺-扩展的实验性玩法.md》。

---

## 5. 挑战码 / 种子 / 存档码

- **挑战好友**：把好友给的 `CZYFK2-…` 粘进去，**按对方码里的难度 + 每一项实验性玩法 + 模式开局**，仅本局生效、不改你的设置，重开还是你自己的模式。码已加密带校验，改一个字符会被拒绝。老版 `CZYFK-XX-种子-分数` 仍可导入。
- **种子**：手动指定种子开局（**只支持字母、数字、emoji**；中文、空格及 `！》《` 等符号会提示「种子格式不支持，仅支持字母和数字」），或一键生成挑战码。同种子 = 同障碍顺序。**输入纯数字会原样保留**（123 就是 123）。
- **存档码**：清浏览器数据/换手机前，导出这串码备份；回来粘回即可恢复历史最高、局数、设置。

> **开发者模式与极限难度**不能导出对战挑战码（命令面板会写明原因）。

## 6. 其它小提示

- **慢放技能**：第 3 波解锁，游戏内右下角圆圈点一下，世界变 0.5× 持续 4 秒，趁机点障碍消除；冷却 10 秒（开发者无冷却）。
- **P 键无敌圆圈**：只有在 **开发者模式 + 电脑模式** 同时开启时才显示（游戏内右下角「无」圆圈）。
- **退出大按钮**：主菜单最下方，点了是「全屏再见页」，不是关程序；**在恐怖模式下它同时是恐怖的终点**（点它才会结束血红界面）。
- **删除存档**：设置里有「删除存档」小按钮（二次确认）。

## 7. v1.6.0 新系统速览

完整的分项说明看同目录这几份：`方块冲刺-v1.6.0功能说明.md`、`方块冲刺-扩展的实验性玩法.md`、`皮肤使用方法-玩家.md`。

### 7.1 新障碍

| 名称 | 外观 | 行为 | 难度 |
|---|---|---|---|
| 巨墙 | 粉色横贯跑道的长带，只留一道白框缺口 | 必须提前找到缺口变道 | 困难（第 4 波起） |
| 急坠 | 橙色倒三角 + 下落拖尾 | 下落速度 1.6 倍 | 进阶（第 2 波起） |
| 相位 | 紫色；虚化时只剩虚线框 | 虚化态可直接穿过，不判死 | 进阶（第 3 波起） |
| 追踪 | 金色，中间一道黑色「眼睛」 | 接近时朝你平移一格，只移一次 | 困难（第 5 波起） |

### 7.2 摇杆 / 切道动画

- **设置 → 摇杆模式**：开启后游戏底部出现可拖动摇杆，左右拖动越阈值变道；关闭则回到点屏左右半区 + 方向键。摇杆区域不会误触。
- 切道现在有平滑动画和一条渐隐尾光。**判定不受影响**——碰撞始终按你实际所在的车道算，动画只是拖影。

### 7.3 新实验性玩法

`密集弹幕`（生成间隔 ×0.62）、`巨墙模式`（每个障碍都是巨墙）、`漂移惯性`（切道视觉会冲过头再回正，不影响判定）。默认关，勾选只作用本局。详见《方块冲刺-扩展的实验性玩法.md》。

### 7.4 皮肤 / 彩蛋

- **关于页黄色版本号标签，1.8 秒内连点 5 次** → 解锁隐藏皮肤「黄金」。
- **设置 → 自主设置皮肤**：粘贴皮肤代码导入，支持纯色 `normal` 和像素画 `pro`，只改玩家方块。格式错误会整份拒绝并逐条列出「第 N 行：原因」。格式见《皮肤使用方法-玩家.md》。

### 7.5 背景音乐

- **设置 → 背景音乐** 开关（默认关，关时零外部请求）+ **音乐设置** 按钮。
- 音乐设置里可存 **3 个自定义地址**；填了就优先播它，全空则每局从内置 4 首随机选。
- **普通模式不可自选**内置曲目；**开发者模式**可指定。
- 播放器是可拖动的浮框，默认右下角，`×` 收起。B 站播放器受平台自动播放限制，通常要在框内点一下才出声。
- 内置 4 首已核验公开有效，全部保留；无效/私密链接不会写进乐库。

## 8. v2.1.5 更新

### 8.1 挑战码（重要变化）

- 新版 `CZYFK2-…` **已加密并带校验位**，内含**难度 + 你开的每一项实验性玩法 + 车道数 + 模式 + 种子 + 分数**。好友导入后严格按同一套条件开局，改一个字符就会提示「被改动过」。
- 「不改动他的设置」= 他本局按你的条件跑，但他的存档设置保持原样，重开还是他自己的模式。
- **开发者模式与极限难度不能导出对战挑战码**。极限局结算页给的是 `CZYBB-JX-…` 装逼码，只能拿去验真伪、炫耀分数，不能开局。
- 老版 `CZYFK-XX-种子-分数` 仍可导入，但结算页会写明「本码是老版挑战码，无法确定是否为真实的模式」。
- 主界面「验证码」可查验专属编码真伪与级别/称号（与商店、账户平级）。

### 8.2 音乐两种显示方式

设置里选 **仅声音** 或 **声音+视频**。仅声音会把播放器画面收成 1×1 隐藏、浮框只留控制条；声音+视频保持可拖动浮框显示画面。B 站可能检测隐藏而暂停，仅声音模式下若没声，点一下框内即可。

### 8.3 障碍教程与「现」技能

- **箭头方块**（橙色倒三角，1.6 倍速）：**连续点击箭头本体 3 下消失**，本体上会显示还剩几下。首次出现有教程。
- 已修复「箭头与双块墙叠在一起把三条道全堵死」——现在始终留一条活路。
- **隐身方块**（紫色虚化态可直接穿过）：右下角新增「现」圆圈，冷却 5 秒，点一下让所有隐身方块现身并 0.5 秒逃走。首次出现有教程。

### 8.4 一车道通关

多车道选 1 改为点击消除玩法：红/蓝/绿障碍分别点 **3 / 5 / 10 下**消除，得 **3 / 5 / 10 分**；没及时点消就撞上失败。累计 **150 分通关** → 白闪 → 宝箱 → 开箱得 +300 最高分、100 金币、隐藏皮肤「黄金」（每存档只领一次）。

### 8.5 商店与金币（测试版）

游戏里会随机冒出金币，**点一下就收进存档**，PT 模式也有。主菜单 →「商店」可花金币买几件占位商品。

### 8.6 种子数字

输入纯数字种子现在**原样保留**（输入 123 就是种子 123），HUD、种子页、复制、结算显示的都是你输入的数字，不再被转成另一串。
