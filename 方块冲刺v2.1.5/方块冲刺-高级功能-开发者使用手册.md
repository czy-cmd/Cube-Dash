# 方块冲刺 · 高级功能 开发者使用手册（维护与扩展）

> 版本对应：v2.1.5（设计 v2.6）
> 面向对象：游戏的维护者 / 想加命令、加难度、加实验开关的人。
> 玩家视角的用法见《方块冲刺-高级功能-玩家使用手册》。

---

## 1. 工程概况

- **形态**：单个 `方块冲刺.html`，零依赖、零外部请求。
- **技术栈**：HTML5 + Canvas 2D（渲染）+ Web Audio（实时合成音效，`audioCtx` 为 null 时全部静默）+ `localStorage`（存档）。
- **脚本结构**：全部逻辑包在一个 IIFE 里：
  ```js
  (function(){'use strict'; ... })();
  ```
  顶层变量（`CONFIG`、`state`、`G`、`save`、`expFlags`、`curDiff` 等）都是 IIFE 内的 `var`，**不挂到 window**。要测试/导出，必须从 `})();` 之前注入导出语句（见 §7）。
- **状态机**：`state` ∈ `menu / playing / paused / adPaused / over`；各 UI 是 `.layer` 面板，`layer(id)` 负责显隐 + 切换 HUD。

## 3. 命令系统（`applyCommand`）

位置：约 1058 行。`applyCommand(low, p, raw)` 收到：

- `low`：整条命令转小写。
- `p`：按空白 `split(/\s+/)` 后的词数组。
- `raw`：原始字符串（带大小写，给 `type on 密码` 这类需要原样密码的命令用）。

### 3.1 解析约定

- 每个命令是一个 `if(p[0]==='xxx'){...}` 分支，最后落到 `return{text:'unknown command'};`。
- **带连字符的命令**（`tp-5-next`、`about-things`）要先归一化：在分支里把 `-` 替换成空格再 split，或用 `p[0].indexOf('about-')===0` 这类前缀判断再 `slice(6)` 取子命令。
  - `tp` 分支：`var tp=(low.replace(/-/g,' ')).split(/\s+/);`
  - `about` 分支：`var sub=(p[0]==='about')?p[1]:p[0].slice(6);`
- 返回值是 `{text, fx?}`：`text` 显示在命令输出区；`fx:'flash'` 触发闪屏。

### 3.2 已实现的命令清单

| 命令 | 实现要点 |
|------|----------|
| `get from enter/in/into dev/into pro/percent N` | 分别设 `exitMode` / `devLevel` / `percent` |
| `url-…` / `url-none` | `addUrl()`，定时 `window.open` |
| `type on/off 密码` | 密码必须 `raw.split(/\s+/)[2]===CONFIG.devPassword`（区分大小写） |
| `kb-true` | 置 `horrorStory=true` → `applyHorrorVisual()`（会话级开关，不写存档） |
| `kb-false` | `endHorror()` 统一收尾：清 `horrorStory`、结局页、独白、`--hgloom`、血色界面 |
| `tp N [next\|M.ago]` | 立即：`G.wave=N-1`；预约：`tpPending={target,after}`，`after` 在每次波次递增时减 1，归零即跳（`M.ago` 的 after = `M+1`） |
| `about-things/choose/command/game/use` | 见 §3.3 |

### 3.3 `about` 四件套（v1.5.0）

- `about-things`：`save.aboutThings=(save.aboutThings||0)+1; writeSave();` —— **永久写存档**。
- `about-choose`：`chooseNoSave=!chooseNoSave;` —— **会话级**开关，`gameOver` 里 `if(!chooseNoSave)writeSave();`。
- `about-command`：`cmdMode=true; buildCmdBook(); layer('cmdMode');` —— 切到冰冷命令模式（`#cmdMode` 层 + `#cmdBook` 书）。
- `about-game`：`startGame();` —— 直接开局（不弹难度）。
- `about-use`：拼一段调试 log（各难度 mul、当前难度、种子、模式码、恐怖/命令/极限状态），返回给输出区。

### 3.4 如何新增一条命令

1. 在 `applyCommand` 里加一个分支（注意连字符/大小写）。
2. 若想在「书」里露脸，往 `COMMANDS` 数组（约 1279 行）加一行 `[命令, 说明]`。
3. 若影响难度/实验/存档，同步 §2、§4、§5 的逻辑与手册。
4. 跑 §7 的冒烟测试，并在 `LOG` 数组（约 1266 行）补一条更新日志。

## 4. 难度系统（v1.5.0）

### 4.1 速度乘子
`difficulty()`（约 571 行）在每段时间轴的 `mul` 上再乘 `CONFIG.diffs[curDiff].mul`：
```js
var d=CONFIG.diffs[curDiff]||CONFIG.diffs.normal;
return {mul:s[1]*d.mul, a:s[2], b:s[3]};
```
`update()` 里波次 3 对残疾模式特判：`*(G.wave===3?(curDiff==='disabled'?0.5:1.3):1)`。

### 4.2 入口流程（`requestStart` / `pickDiff` / `doStartWithDiff`）
- `requestStart(fn)`：设 `pendingStartFn=fn`；**恐怖模式（horrorStory）先把 `curDiff` 重置为 `'normal'` 再直接执行**（防止上一局极限/残疾残留串进恐怖局）；否则 `layer('diffLayer')` 弹难度选择。
- 简单/普通/困难：`pickDiff` 直接 `doStartWithDiff()`。
- 极限/残疾：`pickDiff` 先弹 `diffConfirm` 说明，`diffConfirmYes` 要点 **两次**（第一次把文字改成「真的？再点一次」，`_step` 切到 2）才 `doStartWithDiff()`。
- `doStartWithDiff()`：非极限时 `exitMode=false`（清残留），执行 `pendingStartFn`。

### 4.3 极限模式特殊规则
- `startGame()`：`if(curDiff==='extreme')exitMode=true;`（强制出口开）。
- `exitThreshold(i)`：`if(curDiff==='extreme')return 300*(i+1);`（覆盖普通 100/500/1000）。
- `gameOver()` 极端分支：**按 3 倍**算 highscore（`G.score*3`），然后 `localStorage.removeItem(saveKey)` 永久删档并重置内存 `save`，再 `showOver()` 返回。
- `btnQuit()`（暂停页退出）：极限模式下若 3 倍新高，**主动写回存档**——这就是「见好就收带走 3 倍」的实现点。

### 4.4 残疾模式
- `move(dir)`（约 775 行）：`curDiff==='disabled'` 时，捕获方向、随机延迟 `1000+rand(0..2000)ms`，用 `setTimeout` 在延迟后执行原本的变道（延迟期间再查冷却/边界）。同步不会立即变道。

### 4.5 如何加一档难度
1. `CONFIG.diffs` 加一项 `{name, mul, 你的flag?}`。
2. 若需要出口/删档/延迟等特例，在 `startGame` / `exitThreshold` / `gameOver` / `move` 里按 `curDiff` 分支。
3. `diffLayer` 加一个按钮 + 绑定 `pickDiff('你的key')`。

## 4.6 恐怖模式状态机（v1.5.2 重做）

完整叙事设计见同目录《方块冲刺-恐怖模式设计稿.md》。这里只记代码接线与坑。

**它是会话级状态，不是本局 flag**：`var horrorStory=false`（模块级，不写存档，刷新即失）。

| 函数 | 职责 |
|------|------|
| `applyHorrorVisual()` | 按 `horrorStory \|\| expFlags.horror` 挂/卸 `body.blood`、`#horror.on`；关闭时顺带收 `#horrorText.on` |
| `endHorror()` | **唯一完整收尾**：清 `horrorStory` / `#horrorFinale.on` / `#horrorText.on` / `--hgloom`，再调 `applyHorrorVisual()` |
| `closeHorrorFinale()` | 结局页点击：隐藏层 + **`state='menu'`** + `menuCleared=false` + `resetExp()` + 回菜单，**不清 `horrorStory`** |

**恐怖只在两处结束**：`kb-false` → `endHorror()`；主菜单「退出」大按钮 `btnExit.onclick` → `endHorror()`。
`resetExp()` / `refreshMenu()` / `closeHorrorFinale()` / 死亡都**不能**清 `horrorStory`（v1.5.1 曾修过前两个，v1.5.2 修了后两个）。

**效果接线**（都判 `horrorStory`）：
- `update()`：`--hgloom` 血雾渐浓、`G.heartT` 心跳加速、`G.horrorT` 独白（`horrorLine()`，第 4 波起换池）、`G.darkT` 黑屏闪。
- `render()`：`if(horrorStory)obsColor=…` 障碍恒红；`drawEyes()` 内 `blink=!horrorStory` 且眼睛加红晕。
- `gameOver()`：恐怖分支**直接 `return`**，不调 `showOver()`（所以看不到结算/挑战码），只弹 `#horrorFinale`。
- `requestStart()`：恐怖时 `curDiff='normal'` 后直接执行 `fn`，跳过难度选择，避免上一局极限/残疾残留。
- CSS：`.blood` 下按钮/面板/标题/分数变红；`@keyframes hvig/hscan/hfinale/heyepulse` 持续呼吸。

> ⚠️ **坑：别改 `#horror` 的 z-index**。它是 6，HUD 是 10、`#horrorText` 是 8、界面层是 20。
> 为了「菜单也血红」把它提到 20 以上会盖住 HUD 和独白文字。菜单的恐怖氛围靠 `.blood .btn/.panel/h1` 实现，不改层叠。

> ⚠️ **坑：结局页关闭必须 `state='menu'`**（v1.5.2 修的 bug）。`loop()` 是
> `if(state!=='menu'){render();menuCleared=false;} else if(!menuCleared){menuCleared=true;if(!save.settings.keepDeathBg)clearCanvas();}`。
> 恐怖死亡时 `state` 停在 `'over'`，旧代码结局页点击没复位它 → 每帧重绘死亡冻结帧 + `menuCleared` 反复置 false →
> `clearCanvas()` 永不执行，「死亡定格背景」开关在恐怖模式下完全失效，没勾也一直定格。

## 5. 实验性玩法 & 挑战码 & 种子

- **`expFlags`**：普通对象，每个勾选项是一个 key（如 `flip/chaos/horror/ghost/multilane/reverse`）。`expAny()` 任一为真即实验局。`multilane` 额外把车道数写 `expFlags.lanesN`，`resetRun` 里 `LANES=expFlags.lanesN||3`。
- **`noRecord()`** = `expAny()||challengeExp||commandActive`：决定是否记最高分。
- **`modeCode()`**：按 `exp/challenge/command` 组合返回 `PT/EX/CM/MX/DV`（开发者）。
- **`parseChallenge`**：格式 `CZYFK-<2字母模式>-<种子36进制>-<分数36进制>`；模式 `DV` 视为开发者码拒绝。
- **`parseSeedInput`**：FNV-1a 哈希（基 `2166136261`，`Math.imul(...,16777619)`），支持字母（区分大小写）/数字/符号三类，正则拒绝 emoji 与 CJK。

## 6. 开发者模式 / 隐藏页

- `devLevel`：0 无 / 1 阉割A（调试信息）/ 2 阉割B（+下一波/清障碍）/ 3 完整。
- `refreshDev()`：按 `devLevel` 渲染开发者面板按钮；3 级且 Windows 才显示「代码源码」（`#consoleLayer`，可 `Function(code)()` 任意执行 / 看源码）。
- **隐藏页**：`#secretLayer`（内部页面）、`#nfPage`（404，由 `show404` 触发）。
- **P 键无敌圆圈**：`updateSkillUI` 里 `devLevel>0 && save.settings.pcMode` 双门控才显示。
