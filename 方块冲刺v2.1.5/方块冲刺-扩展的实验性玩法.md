# 方块冲刺 · 扩展的实验性玩法

> 版本：v2.1.5（v1.6.0 起）
> 入口：主菜单 → 实验性玩法 → 勾选 → 按此设置开局
> 开关状态：全部**默认不勾选（关）**，仅对本次勾选后开的那一局生效；进入游戏后本局无法关闭，回主菜单自动全部复位为关。
> 勾选任一项后本局成绩**不记入最高分**，但仍能生成挑战码，前缀 `EX`（叠加命令时为 `MX`）。

---

## 1. 原有 6 项（对照）

| 开关 | 作用 |
|---|---|
| `flip` 重力翻转 | 左右输入反过来 |
| `chaos` 分数乱动 | 分数会乱跳，结算有彩蛋 |
| `horror` 恐怖画风 | 画面变血红（仅视觉，无剧情；与 `kb-true` 完整恐怖模式不同） |
| `ghost` 幽灵方块 | 多出一个半透明幽灵方块 |
| `multilane` 多车道 | 进入时弹窗，点 1~10 选车道数 |
| `reverse` 倒车模式 | 障碍反向而来 |

## 2. v1.6.0 新增 3 项

### 2.1 `barrage` 密集弹幕

- **开关状态**：默认关。勾选开。
- **作用**：所有障碍的生成间隔统一 ×0.62，障碍更密、节奏更紧。对普通单块、双块墙，以及本版新增的巨墙 / 急坠 / 相位 / 追踪**全部生效**。
- **难度定位**：进阶。不新增障碍种类，只压缩喘息时间；与 `rush` 急坠叠加时压力最大。
- **注意**：分数增长更快，但本局不记最高分。

### 2.2 `titan` 巨墙模式

- **开关状态**：默认关。勾选开；车道数 < 3 时不生效。
- **作用**：强制把每一个障碍都变成 `wide` 巨墙——横贯整条跑道、只留一道由种子决定的缺口（白框标出）。生成间隔额外 ×1.35 留出预判时间。
- **难度定位**：困难。必须持续读缺口位置并提前变道，几乎没有临时反应余地。
- **与 `wide` 障碍的区别**：正常游戏里巨墙只是低概率出现的一种障碍；本开关把它变成**唯一**障碍类型。

### 2.3 `drift` 漂移惯性

- **开关状态**：默认关。勾选开。
- **作用**：切道动画从「指数平滑」改成「带阻尼弹簧」，视觉上会略微冲过头再回正，松手后方块继续滑一小段；同时切道瞬间方块有轻微倾斜。
- **难度定位**：趣味向，不增加碰撞难度。
- **关键**：**只改视觉**。`G.lane`（逻辑车道）在 `move()` 调用时立即改变，碰撞、擦边、计分一律读它；`laneVisual` 只用于绘制。开发者模式下的黄色判定框仍画在逻辑车道，可直接验证动画不干扰判定。

## 3. 组合效果

| 组合 | 结果 |
|---|---|
| `barrage` + `rush` | 密集且高速，反应窗口最短 |
| `titan` + `multilane` | 车道越多，找缝越难（最多 10 道只留 1 道） |
| `titan` + `reverse` | 巨墙从下往上压过来，缺口方向不变 |
| `drift` + `flip` | 输入反向 + 视觉漂移，方向感最混乱 |
| 任意实验项 + 高级命令 | 模式码 `MX`，仍可导出挑战码 |
| 任意实验项 + `kb-true` 恐怖模式 | 恐怖模式跳过难度选择并强制普通速度，但实验项照常生效、障碍恒为血红 |

## 3.1 多车道选 1 的特殊玩法（v2.1.5）

`multilane` 且车道数 = 1 时，游戏不再是「无法躲避的死局」，而是切换为**点击消除**玩法（`lane1Mode()`）：

| 障碍 | 点击次数 | 得分 |
|---|---|---|
| 红 `#FF3B3B` | 3 | 3 |
| 蓝 `#3B7BFF` | 5 | 5 |
| 绿 `#3BD66F` | 10 | 10 |

- 障碍上显示剩余点击数；点击命中由 `tapObstacle()` 判定，命中则本次不触发左右移动（一车道本来也没有左右移动）。
- 没及时点消就撞上 → 失败。
- 累计 **150 分** → `lane1Clear()` 白闪 → 宝箱界面 → 开箱得 `+300 最高分 / 100 金币 / 隐藏皮肤「黄金」`，`save.lane1Cleared` 保证每存档只领一次。
- 该模式仍属实验局，不记最高分（通关奖励除外），挑战码前缀仍按 `EX`/`MX` 规则。

## 4. 开发者接线

- 勾选值写入 `expFlags`，由 `$('expOK').onclick` 收集；`resetExp()` 清空并复位所有 `[data-exp]` 复选框。
- `expAny()` 任一为真即实验局；`noRecord()` 据此决定不记最高分；`modeCode()` 据此给 `EX`/`MX`。
- 新增 3 项的作用点：
  - `barrage`：`spawnObstacle()` 内 `var dense=expFlags.barrage?.62:1`，所有分支的 `G.spawnTimer` 都乘它。
  - `titan`：`spawnObstacle()` 开头强制生成 `wide` 并 `return`。
  - `drift`：`loop()` 内 `laneVisual` 改用弹簧积分；`render()` 内给玩家方块加 `ctx.transform` 倾斜。
- 加新项的步骤：在 `expLayer` 加一个 `<label class="chk"><input type="checkbox" data-exp="你的key">…</label>`，再在对应逻辑点判 `expFlags.你的key`。无需改存档结构。
