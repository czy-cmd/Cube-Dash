## 1. 上手：怎么玩

- 点屏幕 **左半区 / 右半区** 移动方块；电脑上也可以用 **← → 方向键**。
- 障碍从上往下（或反向）落下来，**别撞上**。
- 贴着障碍擦过去（相邻车道）可以攒 **倍率**，擦得越多分越高。
- 每过一波，速度会变快。

游戏是纯网页单文件，零依赖；设置、最高分、皮肤都存在浏览器本地。

## 2. 五档难度

从「开始游戏 / 实验性玩法 / 种子 / 挑战好友」进入时，会先弹 **选择难度**（模仿 MC）。

| 难度 | 速度倍率 | 说明 |
|------|---------|------|
| 简单 | ×0.8 | 慢一点，好上手 |
| 普通 | ×1.0 | 标准 |
| 困难 | ×1.2 | 快一点 |
| 极限 | ×1.3 | 死亡永久删档，需二次确认 |
| 残疾 | ×0.7 | 点击延迟 1~3 秒，需二次确认 |

- **二次确认**：点极限或残疾后要连点两次「我确定」，防止手滑。
- **再来一次**：沿用上一局难度，不重弹。
- 恐怖模式下不弹难度，强制普通速度。

**极限规则**：本局死亡 → 本地存档永久删除（最高分、局数、设置全清）。出口分数变成 300/600/900…，结算按 3 倍计分——但只有你**主动退出本局**（不算死亡）才保留，死了全没。要么见好就收，要么赌一把。

**残疾规则**：速度 0.7×（第三波再 ×0.5），每次点击延迟 1~3 秒才执行，方块不等你。

## 3. 主菜单小功能总览

主菜单中间一排小按钮，功能如下（三者平级）：

| 按钮 | 作用 |
|------|------|
| **验证码** | 查验别人发来的「专属编码」是真是假，以及对应的级别和称号 |
| **商店** | 花游戏里捡到的金币买东西（测试版，PT 模式也能进） |
| **账户** | 登录 / 注册，保存你的称号和专属编码（可不登录直接玩） |

其它入口：**高级**（输命令）、**实验性玩法**、**种子**、**挑战好友**、**设置**、**关于**、**更新日志**，最下方是「退出」大按钮（全屏再见页）。

## 4. 高级命令

主菜单点 **高级** → 弹窗点 **确定** → 输入框里输命令后回车。命令不区分大小写；空格和连字符 `-` 大多通用（`tp 5` = `tp-5`）。

### 4.1 常用命令

| 命令 | 作用 | 性质 |
|------|------|------|
| `get from enter` | 开出口模式（跑到出口格子得分） | 本局 |
| `url-网址 [-t 秒]` | 到点自动开网页；`url-none` 关闭 | 本局 |
| `kb-true` / `kb-false` | 开 / 关恐怖模式 | 会话 |
| `tp N` | 立即跳到第 N 波 | 本局 |
| `tp N next` | 下次波次变化后跳到第 N 波 | 本局 |
| `tp N M.ago` | 再过 M+1 次波次变化后跳到 N 波 | 本局 |
| `about-things` | 把一次永久操作写进存档 | 永久 |
| `about-choose` | 本会话结局不写存档（再输一次关闭） | 会话 |
| `about-command` | 进入命令模式 | 本局 |
| `about-game` | 直接开始游戏 | 本局 |

### 4.2 命令模式

输 `about-command` 后，主界面变成冰冷输入框，没有按钮也没有教程。点「书」能展开已知命令清单。输 `about-game` 进游戏，点「离开」回主菜单。

> 有一小部分命令属于维护与调试用途，不写在本册，也不建议普通玩家尝试。

## 5. 实验性玩法

主菜单 → 实验性玩法。勾选后本局**不计入最高分**（但仍能生成挑战码，前缀 `EX`），开启后本局无法关闭。

| 开关 | 效果 |
|------|------|
| 重力翻转 | 左右方向相反 |
| 分数乱动 | 分数会乱跳 |
| 恐怖画风 | 视觉变血红（只是画面，没有剧情） |
| 幽灵方块 | 多出一个幽灵方块 |
| 多车道 | 点 1~10 选车道数 |
| 倒车模式 | 障碍反向而来 |
| 密集弹幕 | 障碍间隔 ×0.62，明显更密 |
| 巨墙模式 | 每个障碍都是横贯跑道、只留一道缝的巨墙 |
| 漂移惯性 | 切道视觉冲过头再回正，只影响画面 |

勾选多个 + 用命令，模式码变成 `MX`（混合）。

## 6. 障碍图鉴与技能

### 6.1 障碍

| 名称 | 外观 | 行为 | 出现波次 |
|------|------|------|---------|
| 单块 / 双块墙 | 普通色块 | 躲开即可 | 入门 |
| 巨墙 | 粉色长带，一道白框缺口 | 提前找缺口变道 | 第 4 波起 |
| 急坠（箭头） | 橙色倒三角 + 拖尾 | 1.6 倍下落速度；**点本体 3 下消除** | 第 2 波起 |
| 相位（隐身） | 紫色，虚化只剩虚线框 | 虚化态可穿过；用「现」技能逼出 | 第 3 波起 |
| 追踪 | 金色，中间黑「眼睛」 | 接近时朝你平移一格（只一次） | 第 5 波起 |

首次遇到箭头 / 隐身方块会弹教程。

### 6.2 技能

- **慢放**：第 3 波解锁，右下角圆圈点一下，世界变 0.5× 持续 4 秒，冷却 10 秒。趁慢放点障碍消除。
- **「现」**：右下角圆圈，冷却 5 秒，点一下让所有隐身方块现身并 0.5 秒逃走。首次出现有教程。

## 7. 挑战码 / 种子 / 存档码

- **挑战好友**：把好友给的 `CZYFK2-…` 码粘进去，按对方码里的难度 + 每一项实验玩法 + 模式开局，**仅本局生效、不改你的设置**，重开还是你自己的模式。码已加密带校验，改一个字符会被拒绝。老版 `CZYFK-XX-种子-分数` 也能导入，但结算页会提示无法确定模式真伪。
- **种子**：手动指定种子开局（**只支持字母、数字、emoji**；中文、空格及 `！》《` 等符号会提示「种子格式不支持，仅支持字母和数字」）。同种子 = 同障碍顺序。输入纯数字会原样保留（123 就是 123）。
- **存档码**：清浏览器数据 / 换手机前，导出这串码备份；回来粘回即可恢复最高分、局数、设置。
- **装逼码**：极限局结算给 `CZYBB-JX-…`，只能验真伪、炫耀分数，不能开局。

> 开发者模式与极限难度不能导出对战挑战码。

## 8. 皮肤与背景音乐

### 皮肤

- **关于页**黄色版本号标签，1.8 秒内连点 5 次 → 解锁隐藏皮肤「黄金」。
- **设置 → 自主设置皮肤**：粘贴皮肤代码导入，支持纯色 `normal` 和像素画 `pro`，只改玩家方块。格式错了整份拒绝并逐条列原因。格式见《皮肤使用方法-玩家.md》。

### 背景音乐

- **设置 → 背景音乐** 开关（默认关，关时零外部请求）+「音乐设置」。
- 音乐设置里可存 3 个自定义地址；填了优先播它，全空则每局从内置 4 首随机选。普通模式不可自选内置曲目。
- 播放器是可拖动浮框，默认右下角，`×` 收起。
- 两种显示方式：**仅声音**（画面收成 1×1，只留控制条）/ **声音+视频**（显示画面）。B 站可能检测隐藏而暂停，仅声音没声时点一下框内即可。

## 9. 一车道通关与商店金币

- 多车道选 **1** 车道时改为点击消除玩法：红 / 蓝 / 绿障碍分别点 **3 / 5 / 10 下**消除，得 **3 / 5 / 10 分**；没及时点消就撞上失败。
- 累计 **150 分通关** → 白闪 → 宝箱 → 得 +300 最高分、100 金币、隐藏皮肤「黄金」（每存档只领一次）。

**商店（测试版）**：游戏里随机冒出金币，点一下收进存档，PT 模式也有。主菜单 →「商店」花金币买几件占位商品。

## 10. 账户（可选）

主菜单 →「账户」，分 **登录** 和 **注册** 两个页签，模仿常见网站：

- **注册**：填账户名 + 密码两次，两次一致才成功，注册后自动登录。
- **登录**：只认已有账户，没注册会提示先注册。
- 账户**非强制**——不登录也能玩全部游戏功能。
- **个人主页**：显示金币 / 最高分、你拿到的称号、以及你的专属编码；里面有一句话提醒你「别忘记把存档码发给开发者哦」。
- 专属编码是你的通关凭证，可在主菜单「验证码」里查验真伪与级别 / 称号。

## 11. 恐怖模式

`kb-true` 开启后是贯穿整个会话的状态（不是一局 buff）：开局、死亡、回菜单、再开局，全程血红，直到你输 `kb-false` 或点主菜单「退出」大按钮才结束。刷新页面会消失（不写存档）。

表现：菜单 / 按钮 / 标题 / 分数全血红；血雾越来越浓、心跳越来越急；自我怀疑独白不断，第 4 波起换更瘆人的台词；障碍与眼睛恒血红、不再眨眼；死亡不弹普通结算，而是三双血红眼睛质问你。轻触结局页回菜单后，界面仍是血红的——它们没走。

> 实验性玩法里的「恐怖画风」只是画面变红、只作用本局，和这里的完整恐怖模式不是一回事。

## 12. 小提示与彩蛋

- **摇杆模式**：设置里开启后，游戏底部出现可拖动摇杆，左右拖过阈值变道；关闭则回到点屏 + 方向键。
- **切道动画**：切道有平滑动画和渐隐尾光，但**判定按你实际所在车道算**，动画只是拖影。
- **死亡定格背景**：设置开关，勾了才保留上一局死亡画面。
- **删除存档**：设置里的小按钮，二次确认。
- 上面的内容大概覆盖 99%。剩下 1% 故意没写——某些组合会触发什么、出口模式里还藏着什么、命令那本「书」之外还有没有别的。自己敲敲看，别全照手册来。
