## 1. 30 秒上手

1. 双击 `方块冲刺.html`（或打开线上分享链接）。
2. 点主菜单 **开始游戏**。
3. 弹出难度选择，先选 **普通**；首局会弹一次基础操作提示，看完点「知道了」。
4. 方块固定在屏幕下方 78% 的位置，只会左右移动；障碍从上往下砸。
5. **点屏幕左半边往左挪，点右半边往右挪**，别等障碍贴脸才动。
6. 死了看结算，觉得可以就再来一局。

> 存档保存在浏览器的 `localStorage`（键名 `fkcc.save.v1`）。换浏览器、清缓存、换设备都不会自动带过去，重要进度请用 **存档码** 备份。

## 2. 操作方式

### 2.1 触屏 / 鼠标

| 操作 | 效果 |
|---|---|
| 点击屏幕左半边 | 向左切一条车道 |
| 点击屏幕右半边 | 向右切一条车道 |
| 点在障碍本体上 | 急坠块：连点 3 下消除；一车道模式：按颜色点 3/5/10 下消除 |
| 慢放期间点在障碍上 | 直接消除该障碍（优先于点屏移动） |
| 摇杆模式开启后 | 拖动底部摇杆，超过阈值变道 |

- 切道有 150ms 冷却，狂点不会瞬移。
- 切道动画是平滑滑过去的，但**判定永远按你逻辑上所在的车道**，动画不影响死活。

### 2.2 键盘

| 按键 | 作用 | 条件 |
|---|---|---|
| `←` / `→` | 左右切道 | 始终可用 |
| `空格` | 开始游戏 | 菜单 / 结算页 |
| `Esc` | 暂停 | 游戏中 |
| `A` / `D` | 左右切道 | 设置里开 **电脑模式** |
| `Q` | 慢放技能 | 电脑模式 |
| `P` | 无敌开关 | 电脑模式 **且** 开发者模式开启 |

### 2.3 摇杆

设置 → **摇杆模式** 开启后，游戏底部出现可拖动摇杆：按住左右拖，超过约 34% 行程触发一次变道，回中不触发。摇杆区域不会误触成点屏。

## 3. 核心规则

### 3.1 车道与判定

- 默认 **3 车道**（实验性玩法可设 1~10 条）。
- 玩家和障碍的碰撞用「方块宽度的 0.8 倍」作判定框。
- 障碍中心与玩家中心的纵向距离小于判定框、且车道重叠 → 死亡（相位方块虚化时除外）。

### 3.2 得分

- 每成功越过一个障碍：**+1 × 当前倍率**。
- 擦边成功额外加 **当前倍率的一半**（向下取整），所以贴边躲比躲远更赚。
- 分数不是按时间给的，躲得越准、倍率越高，涨得越快。

### 3.3 擦边连击（核心爽点）

- 贴着 **单块障碍的相邻车道** 擦过去：连击 +1。
- 隔了 2 条及以上车道通过：连击清零、倍率回到 ×1。
- 双块墙、巨墙等不算擦边。

**倍率表**

| 连击数 | 倍率 |
|---|---|
| 0 ~ 2 | ×1 |
| 3 ~ 5 | ×2 |
| 6 ~ 9 | ×3 |
| ≥ 10 | ×4（上限） |

HUD 中间那根进度条就是「离下一档还差几次」。

### 3.4 阶段（按存活时间自动加速）

| 存活时间 | 速度倍率 | 生成间隔趋势 |
|---|---|---|
| 0 ~ 15 秒 | ×1.0 | 较松 |
| 15 ~ 45 秒 | ×1.2 | 变紧 |
| 45 ~ 90 秒 | ×1.5 | 更紧 |
| 90 ~ 150 秒 | ×1.8 | 很紧 |
| 150 秒以上 | ×2.0 | 最紧 |

### 3.5 波次

- 每 **20~30 秒** 进一波，波次之间约 1.5 秒喘息（障碍会停一下）。
- 五种主题轮换：单块雨 → 双块墙 → 三连窄缝 → 高速直线 → 混合。
- 第 3 波整体速度额外 ×1.3。
- 波次只影响「障碍种类解锁」和主题名，不直接加分。

### 3.6 死亡

- 撞上致命障碍即结束，最高分自动更新（实验局/命令局/挑战局除外）。
- **极限难度死亡会清成绩与设置**（账户、金币、皮肤保留），详见第 6 节。

## 4. 障碍图鉴

| 名称 | 外观 | 行为 | 从第几波出现 |
|---|---|---|---|
| 单块 | 红色方块，带两只眼睛 | 最基础，占一条车道 | 第 1 波 |
| 双块墙 | 橙色，两格并排 | 占两条相邻车道 | 第 1 波（第 2 波以单块为主） |
| 急坠 `rush` | 橙色倒三角 + 拖尾 | 下落速度是普通的 **1.6 倍**；点本体 3 下可消除 | 第 2 波 |
| 相位 `phase` | 紫色，虚化时只剩虚线框 | 周期性实体/虚化切换，**虚化时可直接穿过** | 第 3 波 |
| 巨墙 `wide` | 粉色横贯整条跑道 | 只留一道白框缺口，必须提前找缝 | 第 4 波 |
| 追踪 `tracker` | 金色，中间一道黑色「眼睛」 | 靠近时朝你的车道平移 **一次**，逼你二次变道 | 第 5 波 |

**防堵死机制**：游戏生成障碍时会检查「同屏段所有障碍占用的车道」，如果会占满全部车道，就强制退化成单块并放到已占用的车道上——所以永远存在一条活路，不会出现必死墙。

> 小技巧：急坠块和双块墙可能叠在一起。看到橙色箭头落在双块墙上时，直接点箭头 3 下消掉它，别硬钻。

## 5. 技能与出口

### 5.1 慢放（默认技能）

- **解锁**：进入第 3 波自动解锁。
- **效果**：世界变 0.5 倍速，持续 4 秒（v2.1.6 已修复此前的双重减速，不会再变成 0.25 倍）。
- **冷却**：10 秒（开发者模式无冷却）。
- **额外用法**：慢放期间直接点击障碍本体可将其消除。
- 操作：点右下角「慢」圆圈；电脑模式按 `Q`。

### 5.2 现（针对相位方块）

- 右下角「现」圆圈，冷却 5 秒。
- 点一下：所有 **虚化中的** 相位方块立即变实体，并以 0.5 秒加速逃走（期间不判定）。
- 相位方块第一次出现时会弹教程，教一次后写入存档不再弹。

### 5.3 一车道模式（多车道选 1 时的特殊玩法）

- 没有左右移动，只有一条车道，障碍是红/蓝/绿三色方块。
- 点击消除：红 3 下得 3 分、蓝 5 下得 5 分、绿 10 下得 10 分。
- 累计 **150 分** 通关 → 白闪 → 宝箱。
- 宝箱首次开启：**+300 最高分、+100 金币、解锁隐藏皮肤「黄金」**；每个存档只能领一次，之后是空的。

### 5.4 出口模式

- 通过高级命令 `get from enter` 开启，或选 **极限** 难度自动开启。
- 分数达到阈值时，跑道上出现一个白色方框「出口」，只在某一条车道。
- 出口滑到玩家位置时，**你正好站在那条车道** → 成功走出，进入下一档；站错 → 错过，3~5 秒后重来。
- 普通模式阈值：100 → 500 → 1000 → 1500 → 2000 …（1000 之后每档 +500）。
- 极限模式阈值：300 → 600 → 900 → 1200 …（每次 +300）。

## 6. 五种难度

| 难度 | 速度 | 说明 |
|---|---|---|
| 简单 | ×0.8 | 好上手 |
| 普通 | ×1.0 | 标准 |
| 困难 | ×1.2 | 快一点 |
| 极限 | ×1.3 | 出口模式 + 死亡删档，需二次确认 |
| 残疾 | ×0.7 | 点击延迟 1~3 秒，需二次确认 |

### 极限模式细则

- 强制进入 **出口模式**，出口阈值 300/600/900/1200…
- 死亡时：
  - **最高分、总局数、累计躲避数与全部设置会被清零**，不可恢复；
  - **账户、金币、商店购买、皮肤解锁、等级、称号、专属编码会保留**（v2.1.6 调整，此前是整份存档重置）；
  - 确认弹窗里已按真实范围写明。
- 主动从暂停页「退出」回主菜单（不算死亡）时，本局分数按 **3 倍** 记入最高分。
- 极限模式 **不能导出对战挑战码**，只能生成「装逼码」`CZYBB-JX-…`（见 9.3）。
- 选极限要连点两次「我确定」。

### 残疾模式细则

- 整体速度 ×0.7，第 3 波再额外 ×0.5（更慢）。
- 每次点击会随机延迟 **1~3 秒** 才真正执行，延迟期间再检查边界与冷却。
- 同样要连点两次确认。

## 7. 实验性玩法

入口：主菜单 → **实验性玩法**。勾选后点「按此设置开局」。

> 规则：**本局不记最高分**，但仍可生成挑战码；**开局后无法关闭**，只能打完或重开。

| 开关 | 效果 |
|---|---|
| 重力翻转 `flip` | 左右方向相反 |
| 分数乱动 `chaos` | 显示分数会随机抖动；结算分数贴纸显示负数，连点 5 下才露出真实分数 |
| 恐怖画风 `horror` | 画面变血红（只有视觉，没有剧情） |
| 幽灵方块 `ghost` | 跑道边缘多一个半透明幽灵方块 |
| 多车道 `multilane` | 开局前弹 1~10 选车道数；选 1 进入点击消除玩法 |
| 倒车模式 `reverse` | 障碍从下往上反向而来 |
| 密集弹幕 `barrage` | 所有障碍生成间隔 ×0.62，明显更密 |
| 巨墙模式 `titan` | 每个障碍都是横贯跑道、只留一道缝的巨墙 |
| 漂移惯性 `drift` | 切道视觉会冲过头再回正；只影响动画，不影响判定 |

组合勾选 + 命令状态会让模式码变成 `MX`。

## 9. 挑战码 · 种子 · 存档码

### 9.1 种子

- **同一种子 = 同一串障碍顺序**（障碍生成只由种子决定）。
- 支持字母（区分大小写）、数字、emoji；纯数字会原样当数值种子。
- **不支持**中文和大部分特殊符号（全角符号如 `》` 会被拒绝）。
- 种子面板可查看当前种子、复制种子、用种子开局。

### 9.2 挑战码（`CZYFK2-…`）

- 由结算页或种子面板生成，格式 `CZYFK2-<密文>-<6位校验>`。
- 里面打包了：难度、每一项实验性开关、车道数、模式标志（实验/命令/出口）、种子、分数。
- 好友粘贴后 **严格按这套条件开局**，不会改动好友自己的设置，只作用于这一局。
- 改任何一个字符都会提示「被改动过」。
- **限制**：开发者模式、极限模式不能生成对战挑战码。
- 老版本码 `CZYFK-XX-种子-分数`、`FKCC-Q1:…` 仍可导入，但只能按普通难度 + 大类复现，结算页会标注「老码，无法确定真实模式」。

### 9.3 装逼码（`CZYBB-JX-…`）

- 极限模式专用，只打包分数。
- 只能拿去「挑战好友」验证真伪、炫耀，**不能开局**。
- 改一个字符就验不过。

### 9.4 存档码（`FKCC1:…`）

- 设置 → 存档码 → 导出 / 导入。
- 内容是整份存档的 Base64（含设置、最高分、局数、金币、账户、皮肤、编码等）。
- **没有加密、没有签名**：能备份，也能被随意改写；不要把自己的存档码发给不信任的人（里面有账户密码明文）。
- 导入时只合并最高分/局数/设置等部分字段，不是整份覆盖。

## 10. 金币与商店

- 游戏中每隔 6~13 秒会随机冒出一枚「¥」，点一下得 **1~5 金币**，6 秒没点会消失。
- 金币与最高分无关，普通模式也能捡。
- 商店（测试版）商品：

| 商品 | 价格 | 效果 |
|---|---|---|
| 「测试员」称号 | 20 | 只是称号，没有实际作用 |
| 隐形气泡 | 50 | 看不见的气泡，纯整活 |
| 霓虹配色（默认） | 10 | 切回默认配色 |
| 黄金皮肤 | 80 | 必须先解锁（关于页连点 5 次，或一车道宝箱），否则显示「未解锁」且不可购买 |

> 金币和商店都写在本地存档里：设置里主动「删除存档」会一起没；极限死亡只清成绩与设置，金币保留。

## 11. 账户 · 称号 · 验证码

### 11.1 账户

- 主菜单 → 账户：注册 / 登录 / 退出 / 个人主页。
- 账户名最多 20 字，密码任意非空；**纯本地**，没有服务器、不跨设备同步。
- 不登录也能正常玩，账户只用于展示昵称、金币、称号和专属编码。
- 密码是本机明文保存的，别用真实重要密码。

### 11.2 等级与称号

- 5 个等级目标：100 / 300 / 600 / 1000 / 1500 分。
- 达标奖励：金币 500 / 1200 / 2500 / 5000 / 10000，并解锁对应称号：

| 等级 | 称号 |
|---|---|
| 1 | 初露锋芒 |
| 2 | 渐入佳境 |
| 3 | 势不可挡 |
| 4 | 登峰造极 |
| 5 | 传说 |

- 等级不是自动累计的：需要 **输入别人给的等级码**（在「挑战好友」里粘贴）开一局，在这一局里达到目标分才算达成，奖励每个等级只能领一次。
- 达成后会生成一枚 **专属称号码** `CZYBD-…`，可在「验证码」处验真。

### 11.3 验证码

- 支持两种：等级码 `CZYFK2-…`、称号码 `CZYBD-…`。
- 有效会显示「真实 · 第 N 级 · 称号 · 目标分数」；被改过则显示无效。
- 验证只证明这串码是这套算法生成的，不代表分数真的打出来过。

## 12. 皮肤代码教程

入口：设置 → **自主设置皮肤**。
作用范围：**只改玩家方块外观**，障碍、背景、网格、HUD 都不变。

### 12.1 两种模式

| 模式 | 声明 | 效果 |
|---|---|---|
| normal | `size = normal` | 整个方块一种纯色 |
| pro | `size = pro` | 切成 w×h 像素格，逐格上色 |

### 12.2 语句表

| 语句 | 含义 | 要求 |
|---|---|---|
| `size = normal` / `size = pro` | 声明模式 | 必须写，且只能写一次 |
| `size.color(颜色)` | 设置纯色 | normal 必写 |
| `size.x_y(w,h)` | 网格宽高 | pro 必写，各 1~16 |
| `size.pro.名字 = [` | 开始定义像素表 | 名字自取，英文/数字/下划线 |
| `[[颜色],[颜色],…],` | 像素表的一行 | 每格一个颜色，行尾逗号 |
| `]` | 结束像素表 | 单独一行 |
| `use(size.pro.名字)` | 指定用哪个像素表 | pro 必写 |

### 12.3 颜色的四种写法

1. 十色名（不区分大小写）：`red` `orange` `yellow` `green` `cyan` `blue` `purple` `pink` `white` `black`
2. RGB：`255,0,128`（每项 0~255）
3. 十六进制：`#FF00AA`
4. 空格子 `[]`：透明，露出背景

> `#` 写在行首或前面有空格时是注释；`#FF00AA` 里的 `#` 不会被当注释。

### 12.4 示例一：纯色

```
size = normal
size.color(red)
```

也可以：

```
size = normal
size.color(255,0,128)
```

### 12.5 示例二：3×2 像素画

```
size = pro
size.x_y(3,2)
size.pro.mine = [
[[red],[green],[blue]],
[[255,255,255],[100,203,102],[]]
]
use(size.pro.mine)
```

效果：上排红/绿/蓝，下排白/自定义青绿/透明。

### 12.6 导入与还原

1. 粘贴代码 → 点「导入并应用」。
2. 成功显示绿色提示；失败显示 **每一处问题的行号和原因**。
3. 失败是 **整份拒绝**，不会应用一半。
4. 点「恢复默认」回到霓虹配色 + 默认方块。

## 14. 恐怖模式

**开启方式**：高级命令面板输入 `kb-true`（不在实验性玩法勾选里）。
**关闭方式**：输入 `kb-false`，或点主菜单最下方的「退出」大按钮。

它是 **会话级状态**，不是一局 buff：

- 开启后，开局、死亡、回菜单、再开局全程血红，直到你主动退出；
- 不写存档，刷新页面即消失；
- 不弹难度选择，强制普通速度（避免把极限删档/残疾延迟带进来）。

表现：

- 菜单、按钮、标题、分数全部变血色，血雾暗角持续呼吸并随存活时间变浓；
- 心跳声越来越急；

- 死亡时不弹普通结算，方块停下，三双血红眼睛质问「我……是谁？为什么存在？」；
- 轻触结局页回菜单后，界面仍然是血红的。

> 区分：实验性玩法里的「恐怖画风」只有视觉，没有剧情，且只作用本局；`kb-true` 才是完整恐怖模式。

入口：主菜单 → **高级** → 确定 → 输入命令 → 回车。

## 17. 常见问题

**Q：换手机/清缓存后进度没了？**
A：存档只在当前浏览器。提前用「存档码」导出备份，回来粘贴导入即可（只合并最高分、局数、设置）。

**Q：挑战码导入后我的设置会变吗？**
A：不会。挑战码只作用于那一局，不改你的难度、实验开关和存档。

**Q：为什么打完了不记最高分？**
A：实验性玩法、命令模式、挑战码导入的对局都不记最高分；开发者模式还会禁止导出挑战码。

**Q：极限难度死了，会丢什么？**
A：v2.1.6 起只清 **最高分、局数、累计躲避、设置**；账户、金币、皮肤、等级与称号保留。死亡仍不可撤销，只是不再连账户一起清。

**Q：慢放是 0.5 倍吗？**
A：是。v2.1.6 修掉了此前的双重叠加问题，现在稳定 0.5 倍持续 4 秒，冷却 10 秒。

**Q：关掉页面再打开，还要重新登录吗？**
A：不用。v2.1.6 会从存档里恢复上次登录的账户；管理员权限仍然需要在「高级」里重新输入命令。

**Q：没有声音？**
A：音效需要一次用户点击后才会解锁音频上下文；背景音乐默认关闭，且 B 站播放器要手动点播放。

**Q：画面卡？**
A：游戏每帧全屏重绘，低端设备建议关闭背景音乐视频画面（用「仅声音」）、关闭抽象字幕。

**Q：分享链接打不开/显示 404？**
A：分享链接依赖 cookie 授权与跳转，直接抓原始文件会失败，用浏览器正常打开即可。
