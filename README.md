### 🚀 v2.1.6 版本更新内容

**🐛 Bug 修复与优化：**
* **慢放机制**：修复了慢放技能双重减速的问题。
* **极限难度死亡处理**：极难模式下死亡不再清空所有数据，现在会保留账户、金币、皮肤和称号。
* **渲染与随机数**：引入独立的渲染随机流 `rngVisual`，让种子复现更加稳定；修复了开局瞬间冒出金币的 Bug。
* **界面启动**：优化了启动时的界面复位逻辑（告别快照残留），并修复了登录态的恢复问题。

**🎯 玩法与机制调整：**
* **得分优化**：出口模式阈值（100/500/1000 后）每档增加 500；擦边现在会额外增加半个倍率分。
* **商店调整**：黄金皮肤现在需要先解锁才能购买。
* **新手引导**：首次开局增加了基础教程。
* **结算面板**：补充了用时、条件与种子信息的显示。

### 🕹️ 如何游玩
1. 在下方 **Assets** 区域下载 `方块冲刺.html` 文件。
2. 双击该 HTML 文件，使用现代浏览器（如 Chrome / Edge）打开即可开始游戏。
3. 操作方式：点击屏幕左/右半区（或使用键盘方向键）进行变道。
